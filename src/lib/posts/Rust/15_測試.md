# 15. 測試

### 15.1 單元測試

與程式碼放在同一檔案：

```rust
pub fn add(a: i32, b: i32) -> i32 {
    a + b
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn it_adds() {
        assert_eq!(add(2, 3), 5);
    }

    #[test]
    #[should_panic(expected = "除以零")]
    fn divide_by_zero() {
        panic!("除以零");
    }

    #[test]
    fn with_result() -> Result<(), String> {
        if add(1, 1) == 2 { Ok(()) } else { Err("計算錯誤".into()) }
    }

    #[test]
    #[ignore]
    fn slow_test() { /* 預設跳過 */ }
}
```

常用斷言：`assert!`、`assert_eq!`、`assert_ne!`。

### 15.2 整合測試

放在專案根目錄 `tests/`，只能使用 crate 的公開 API：

```
my_crate/
├── src/lib.rs
└── tests/
    └── integration_test.rs
```

### 15.3 文件測試

文件註解中的程式碼區塊會被當成測試執行：

```rust
/// 兩數相加
///
/// ```
/// let r = my_crate::add(1, 2);
/// assert_eq!(r, 3);
/// ```
pub fn add(a: i32, b: i32) -> i32 { a + b }
```

### 15.4 執行測試

```bash
cargo test                    # 全部
cargo test it_adds            # 名稱過濾
cargo test -- --nocapture     # 顯示 println! 輸出
cargo test -- --ignored       # 只跑被忽略的
```
