# 14. 模組與套件管理

### 14.1 名詞對照

| 名詞 | 說明 |
|------|------|
| **Package** | Cargo 的專案單位（含 `Cargo.toml`） |
| **Crate** | 編譯單位，分為 binary 與 library |
| **Module** | crate 內的命名空間與可見性控制 |
| **Path** | 指向項目的路徑，如 `crate::a::b` |

### 14.2 模組

```rust
// src/main.rs
mod garden {
    pub mod vegetables {
        #[derive(Debug)]
        pub struct Asparagus {
            pub name: String,
            id: u32,            // 預設私有
        }
        impl Asparagus {
            pub fn new(name: &str) -> Self {
                Self { name: name.to_string(), id: 1 }
            }
        }
    }
}

use garden::vegetables::Asparagus;

fn main() {
    let a = Asparagus::new("蘆筍");
    println!("{a:?}");
}
```

預設一切皆**私有**，需 `pub` 才能公開。

### 14.3 拆分為多個檔案

```
src/
├── main.rs
├── garden.rs            // mod garden;
└── garden/
    └── vegetables.rs    // garden.rs 內 pub mod vegetables;
```

```rust
// main.rs
mod garden;
use garden::vegetables::Asparagus;
```

### 14.4 `use` 的常見寫法

```rust
use std::collections::HashMap;
use std::io::{self, Write};      // 同時匯入 io 與 Write
use std::fmt::Result as FmtResult;  // 別名
use std::collections::*;         // 萬用匯入（不建議濫用）
```

### 14.5 使用第三方 Crate

```bash
cargo add rand
```

```rust
use rand::Rng;

fn main() {
    let n: u32 = rand::thread_rng().gen_range(1..=100);
    println!("{n}");
}
```

> 套件搜尋：https://crates.io ；API 文件：https://docs.rs

### 14.6 Workspace（多套件專案）

```toml
# 根目錄 Cargo.toml
[workspace]
members = ["app", "core", "utils"]

```
