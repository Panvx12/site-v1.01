# 13. 並行處理

Rust 的口號：**Fearless Concurrency（無懼並行）**。所有權與型別系統能在編譯期擋掉資料競爭。

### 13.1 建立執行緒

```rust
use std::thread;

fn main() {
    let handle = thread::spawn(|| {
        for i in 1..5 {
            println!("子執行緒 {i}");
        }
    });

    for i in 1..3 {
        println!("主執行緒 {i}");
    }
    handle.join().unwrap();   // 等待子執行緒結束
}
```

搭配 `move` 轉移所有權：

```rust
let v = vec![1, 2, 3];
let h = thread::spawn(move || {
    println!("{v:?}");
});
h.join().unwrap();
```

### 13.2 訊息傳遞（Channel）

```rust
use std::sync::mpsc;
use std::thread;

let (tx, rx) = mpsc::channel();

for id in 0..3 {
    let tx = tx.clone();
    thread::spawn(move || {
        tx.send(format!("worker {id} 完成")).unwrap();
    });
}
drop(tx);                      // 關閉原始發送端

for msg in rx {                // 所有發送端關閉後迴圈結束
    println!("{msg}");
}
```

### 13.3 共享狀態：`Arc<Mutex<T>>`

```rust
use std::sync::{Arc, Mutex};
use std::thread;

let counter = Arc::new(Mutex::new(0));
let mut handles = vec![];

for _ in 0..10 {
    let counter = Arc::clone(&counter);
    handles.push(thread::spawn(move || {
        let mut num = counter.lock().unwrap();
        *num += 1;
    }));
}
for h in handles {
    h.join().unwrap();
}
println!("結果 = {}", *counter.lock().unwrap());   // 10
```

### 13.4 `Send` 與 `Sync`

| Trait | 意義 |
|-------|------|
| `Send` | 型別的**所有權**可以安全地轉移到另一個執行緒 |
| `Sync` | 型別的**參考**可以安全地被多個執行緒共享 |

`Rc<T>` 不是 `Send`，編譯器會拒絕將它送進執行緒 —— 這就是為何多執行緒要用 `Arc`。

### 13.5 非同步（async/await）簡介

Rust 內建 `async/await` 語法，但**執行階段（runtime）需由第三方提供**，最常用的是 **Tokio**：

```toml
# Cargo.toml
[dependencies]
tokio = { version = "1", features = ["full"] }
```

```rust
#[tokio::main]
async fn main() {
    let t1 = tokio::spawn(async { 1 + 1 });
    let r = t1.await.unwrap();
    println!("{r}");
}
```

| | 執行緒 | async |
|---|-------|-------|
| 適合 | CPU 密集型 | I/O 密集型（網路、檔案） |
| 成本 | 每條執行緒較重 | 輕量任務，可數萬並行 |
