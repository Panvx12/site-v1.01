# 11. 閉包與迭代器

### 11.1 閉包（Closure）

```rust
let add_one = |x: i32| x + 1;
let sum = |a, b| a + b;
println!("{}", add_one(5));

// 捕捉環境
let factor = 3;
let times = |x| x * factor;
println!("{}", times(4));

// move：強制取得所有權（常用於執行緒）
let data = vec![1, 2, 3];
let owns = move || println!("{data:?}");
owns();
```

三種閉包 Trait：

| Trait | 行為 |
|-------|------|
| `Fn` | 不可變借用環境，可重複呼叫 |
| `FnMut` | 可變借用環境，可修改狀態 |
| `FnOnce` | 取得所有權，只能呼叫一次 |

### 11.2 迭代器（Iterator）

迭代器是**惰性**的：不呼叫消費方法就不會執行。

```rust
let v = vec![1, 2, 3, 4, 5];

// 轉換器（adapter）：map、filter ...
// 消費器（consumer）：collect、sum ...
let result: Vec<i32> = v.iter()
    .filter(|&&x| x % 2 == 1)
    .map(|x| x * x)
    .collect();
println!("{result:?}");   // [1, 9, 25]

let total: i32 = v.iter().sum();
let max = v.iter().max();
let any_big = v.iter().any(|&x| x > 4);
```

三種取得迭代器的方式：

| 方法 | 產生的項目 |
|------|-----------|
| `iter()` | `&T` |
| `iter_mut()` | `&mut T` |
| `into_iter()` | `T`（取得所有權） |

常用方法速查：

```rust
v.iter().enumerate();                // (索引, 值)
v.iter().zip(other.iter());          // 配對
v.iter().skip(1).take(3);            // 略過/取前 n
v.iter().rev();                      // 反轉
v.chunks(2);                         // 分塊
v.iter().fold(0, |acc, x| acc + x);  // 摺疊
v.iter().flat_map(|x| vec![*x; 2]);  // 攤平
```

### 11.3 自訂迭代器

```rust
struct Counter { n: u32 }

impl Iterator for Counter {
    type Item = u32;
    fn next(&mut self) -> Option<u32> {
        if self.n < 5 {
            self.n += 1;
            Some(self.n)
        } else {
            None
        }
    }
}

let sum: u32 = Counter { n: 0 }.zip(Counter { n: 0 }.skip(1))
    .map(|(a, b)| a * b)
    .filter(|x| x % 3 == 0)
    .sum();
```

> 迭代器是「零成本抽象」的代表：通常會被最佳化到與手寫迴圈同等速度。
