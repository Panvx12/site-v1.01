# 附錄：速查表

### A. 所有權速記

```
賦值/傳參 = 移動（Move），除非型別實作 Copy
&T       = 唯讀借用（可有多個）
&mut T   = 獨佔可變借用（同時只能一個）
參考必須比被參考的值「活得短」
```

### B. 字串型別選擇

```
需要擁有、可修改   → String
只需讀取/函式參數  → &str
```

### C. 錯誤處理選擇

```
可能不存在          → Option<T>
可能失敗            → Result<T, E>
向上傳遞            → ?
程式 bug / 不可能   → panic!、unwrap、expect
```

### D. 常用屬性（Attributes）

```rust
#[derive(Debug, Clone)]   // 自動實作 trait
#[allow(dead_code)]       // 抑制警告
#[cfg(test)]              // 僅測試時編譯
#[inline]                 // 內聯建議
#[must_use]               // 回傳值不可忽略
```
