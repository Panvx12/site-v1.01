# 16. 學習路線與資源

### 16.1 建議學習路線

| 階段 | 內容 | 目標 |
|------|------|------|
| 第 1 週 | 安裝、基本語法、流程控制 | 能寫簡單小程式 |
| 第 2 週 | **所有權、借用、切片** | 理解並習慣編譯器報錯 |
| 第 3 週 | struct、enum、match、錯誤處理 | 能設計資料模型 |
| 第 4 週 | 集合、泛型、Trait、生命週期 | 能寫可重用的程式 |
| 第 5 週 | 閉包、迭代器、智慧指標 | 寫出慣用（idiomatic）Rust |
| 第 6 週 | 並行、async、模組與測試 | 完成實戰專案 |

### 16.2 實戰專案建議

1. **命令列待辦清單**（檔案讀寫、struct、錯誤處理）
2. **簡易 grep（minigrep）**（參數解析、迭代器、測試）
3. **多執行緒網頁爬蟲**（`reqwest`、Tokio）
4. **簡易 HTTP 伺服器**（`axum`）
5. **猜數字 / 貪食蛇遊戲**（`rand`、`bevy` 或終端 UI `ratatui`）

### 16.3 常見新手卡關點與對策

| 問題 | 對策 |
|------|------|
| `value borrowed here after move` | 改用參考 `&`，或必要時 `.clone()` |
| `cannot borrow as mutable more than once` | 縮短參考生命週期，拆分作用域 |
| `missing lifetime specifier` | 加上生命週期標註，或改回傳擁有所有權的型別 |
| 對生命週期感到困惑 | 先用 `String` / `.clone()` 寫出能動的版本，再逐步最佳化 |
| 編譯錯誤很多 | **仔細閱讀錯誤訊息**，Rust 的錯誤提示通常附有修正建議 |

### 16.4 推薦資源

**官方**
- 《The Rust Programming Language》（俗稱 The Book）：https://doc.rust-lang.org/book/
- Rust By Example：https://doc.rust-lang.org/rust-by-example/
- Rustlings（互動式小練習）：https://github.com/rust-lang/rustlings
- 標準庫文件：https://doc.rust-lang.org/std/
- Rust Playground（線上執行）：https://play.rust-lang.org/

**進階**
- 《Rust for Rustaceans》（Jon Gjengset）
- 《Programming Rust》（O'Reilly）
- The Rustonomicon（unsafe Rust）：https://doc.rust-lang.org/nomicon/
- Async Book：https://rust-lang.github.io/async-book/

**常用 Crate**

| 用途 | Crate |
|------|-------|
| 序列化 | `serde`, `serde_json` |
| 命令列參數 | `clap` |
| 非同步 | `tokio` |
| HTTP 客戶端 | `reqwest` |
| Web 框架 | `axum`, `actix-web` |
| 錯誤處理 | `anyhow`, `thiserror` |
| 日誌 | `tracing`, `log` |
| 資料庫 | `sqlx`, `diesel` |
| 平行運算 | `rayon` |
