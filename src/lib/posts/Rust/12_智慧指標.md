# 12. 智慧指標

### 12.1 `Box<T>`：堆積配置

```rust
let b = Box::new(5);
println!("{b}");

// 遞迴型別需要 Box
enum List {
    Cons(i32, Box<List>),
    Nil,
}
```

用途：型別大小在編譯期未知（遞迴型別）、轉移大型資料所有權、trait 物件。

### 12.2 `Rc<T>`：單執行緒多重擁有者

```rust
use std::rc::Rc;

let a = Rc::new(String::from("shared"));
let b = Rc::clone(&a);            // 只增加參考計數
println!("計數 = {}", Rc::strong_count(&a));   // 2
```

### 12.3 `RefCell<T>`：內部可變性

把借用檢查從**編譯期**推遲到**執行期**（違規會 panic）：

```rust
use std::cell::RefCell;
use std::rc::Rc;

let shared = Rc::new(RefCell::new(vec![1, 2]));
shared.borrow_mut().push(3);
println!("{:?}", shared.borrow());
```

常見組合：`Rc<RefCell<T>>`（單執行緒共享可變資料）。

### 12.4 `Weak<T>`：避免循環參考

`Rc` 互相指向會造成記憶體洩漏，可用 `Weak` 打破循環（例如樹的 parent 指標）。

### 12.5 選擇指南

| 需求 | 選擇 |
|------|------|
| 單一擁有者的堆積資料 | `Box<T>` |
| 單執行緒、多擁有者 | `Rc<T>` |
| 多執行緒、多擁有者 | `Arc<T>` |
| 需要內部可變性（單執行緒） | `RefCell<T>` |
| 需要內部可變性（多執行緒） | `Mutex<T>` / `RwLock<T>` |
