# 1. Rust 簡介

### 1.1 Rust 是什麼？

Rust 是一門**系統程式語言**，強調三件事：

- **安全（Safety）**：在編譯期就杜絕空指標、懸垂指標、資料競爭（data race）。
- **效能（Performance）**：零成本抽象（zero-cost abstractions），無垃圾回收器（GC），效能接近 C/C++。
- **並行（Concurrency）**：型別系統幫你避免多執行緒的常見錯誤。

### 1.2 適用場景

| 領域 | 範例 |
|------|------|
| 系統/作業系統 | 核心模組、驅動程式 |
| 網路服務 | Web 後端（Axum、Actix-web） |
| 命令列工具 | ripgrep、fd、bat |
| WebAssembly | 瀏覽器端高效能運算 |
| 嵌入式 | 微控制器開發 |
| 區塊鏈/遊戲引擎 | Solana、Bevy |

### 1.3 與其他語言比較

| 特性 | Rust | C/C++ | Go | Python |
|------|------|-------|----|--------|
| 記憶體管理 | 所有權系統 | 手動 | GC | GC |
| 記憶體安全 | 編譯期保證 | 靠開發者 | 有 | 有 |
| 執行效能 | 極高 | 極高 | 高 | 較低 |
| 學習曲線 | 較陡 | 陡 | 平緩 | 平緩 |
