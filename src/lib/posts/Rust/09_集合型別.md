# 9. 集合型別

### 9.1 `Vec<T>`

```rust
let mut v: Vec<i32> = Vec::new();
v.push(1);
v.push(2);
let v2 = vec![10, 20, 30];

// 存取
let third = &v2[2];             // 越界會 panic
let maybe = v2.get(5);          // 回傳 Option，較安全

// 走訪
for x in &v2 { println!("{x}"); }
for x in &mut v { *x += 1; }    // 修改需解參考
```

> 取得元素參考後，若對 `Vec` 做 `push`，可能因重新配置而使參考失效 —— 借用檢查器會阻止這種情況。

### 9.2 `String` 與 `&str`

```rust
let mut s = String::new();
s.push_str("你好");
s.push('！');
let s2 = String::from("world");
let s3 = format!("{s}-{s2}");

// 走訪
for c in "你好".chars() { println!("{c}"); }   // 依字元
for b in "你好".bytes() { println!("{b}"); }   // 依位元組
```

| | `String` | `&str` |
|---|---------|--------|
| 擁有所有權 | ✅ | ❌（借用） |
| 可增長 | ✅ | ❌ |
| 位置 | heap | 任意（字面值在二進位檔中） |

### 9.3 `HashMap<K, V>`

```rust
use std::collections::HashMap;

let mut scores = HashMap::new();
scores.insert("藍隊", 10);
scores.insert("紅隊", 50);

// 讀取
if let Some(s) = scores.get("藍隊") {
    println!("{s}");
}

// 不存在才插入
scores.entry("黃隊").or_insert(30);

// 計數經典範例
let text = "hello world wonderful world";
let mut count: HashMap<&str, i32> = HashMap::new();
for word in text.split_whitespace() {
    *count.entry(word).or_insert(0) += 1;
}
println!("{count:?}");
```
