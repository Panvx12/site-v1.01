# 6. 結構體與列舉

### 6.1 結構體（struct）

```rust
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    let mut user = User {
        name: String::from("小明"),
        email: String::from("ming@example.com"),
        age: 20,
        active: true,
    };
    user.age += 1;

    // 結構更新語法
    let user2 = User {
        name: String::from("小華"),
        ..user          // 其餘欄位取自 user（注意：可能發生 move）
    };
}
```

**元組結構體與單元結構體**

```rust
struct Color(u8, u8, u8);
struct Marker;           // 無欄位
```

### 6.2 方法與關聯函式（impl）

```rust
#[derive(Debug)]
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // 關聯函式（類似靜態方法），以 :: 呼叫
    fn square(size: u32) -> Self {
        Self { width: size, height: size }
    }

    // 方法：第一個參數為 self
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn scale(&mut self, k: u32) {
        self.width *= k;
        self.height *= k;
    }
}

fn main() {
    let mut r = Rectangle { width: 3, height: 4 };
    println!("面積 = {}", r.area());
    r.scale(2);
    println!("{r:?}");
    let sq = Rectangle::square(5);
    println!("{sq:#?}");
}
```

`self` 的三種形式：

| 寫法 | 意義 |
|------|------|
| `&self` | 不可變借用（最常見） |
| `&mut self` | 可變借用 |
| `self` | 取得所有權（常用於轉換型方法） |

### 6.3 列舉（enum）

Rust 的 enum 可以**攜帶資料**，威力遠大於 C 風格列舉：

```rust
enum Message {
    Quit,                         // 無資料
    Move { x: i32, y: i32 },      // 具名欄位
    Write(String),                // 單一值
    ChangeColor(u8, u8, u8),      // 多個值
}

impl Message {
    fn describe(&self) {
        match self {
            Message::Quit => println!("退出"),
            Message::Move { x, y } => println!("移動到 ({x}, {y})"),
            Message::Write(text) => println!("文字：{text}"),
            Message::ChangeColor(r, g, b) => println!("顏色 #{r:02x}{g:02x}{b:02x}"),
        }
    }
}
```

### 6.4 `Option<T>`：沒有 null

Rust **沒有 null**，改用標準庫的 `Option`：

```rust
enum Option<T> {
    Some(T),
    None,
}
```

```rust
let some_number: Option<i32> = Some(5);
let absent: Option<i32> = None;

// 必須處理 None 才能取值，編譯器強制你思考
match some_number {
    Some(n) => println!("值為 {n}"),
    None => println!("沒有值"),
}
```

常用方法：

```rust
let x: Option<i32> = Some(4);
x.unwrap_or(0);                  // 4（None 時為 0）
x.map(|n| n * 2);                // Some(8)
x.is_some();                     // true
x.and_then(|n| n.checked_sub(10)); // 鏈式處理
```
