# 3. 基本語法

### 3.1 變數與可變性

Rust 變數**預設不可變**：

```rust
let x = 5;
// x = 6;          // ❌ 編譯錯誤
let mut y = 5;
y = 6;             // ✅ 可變
```

常數與遮蔽（shadowing）：

```rust
const MAX_POINTS: u32 = 100_000;   // 必須標註型別

let spaces = "   ";
let spaces = spaces.len();         // 遮蔽：可改變型別
```

### 3.2 資料型別

**純量型別（Scalar）**

| 類別 | 型別 |
|------|------|
| 整數 | `i8 i16 i32 i64 i128 isize`、`u8 u16 u32 u64 u128 usize` |
| 浮點數 | `f32`、`f64` |
| 布林 | `bool` |
| 字元 | `char`（4 bytes，Unicode） |

**複合型別（Compound）**

```rust
// 元組 Tuple：固定長度、可混合型別
let tup: (i32, f64, char) = (500, 6.4, 'R');
let (a, b, c) = tup;          // 解構
println!("{}", tup.0);

// 陣列 Array：固定長度、同型別
let arr = [1, 2, 3, 4, 5];
let zeros = [0; 10];          // 10 個 0
println!("{}", arr[0]);
```

> ⚠️ 整數溢位：debug 模式會 panic，release 模式會環繞（wrap）。可使用 `checked_add`、`wrapping_add`、`saturating_add` 明確處理。

### 3.3 函式

```rust
fn add(a: i32, b: i32) -> i32 {
    a + b            // 最後一個運算式沒有分號 → 即為回傳值
}

fn main() {
    let result = add(3, 4);
    println!("3 + 4 = {result}");   // 行內格式化
}
```

**重點：Rust 是「運算式導向」語言**。區塊 `{ ... }` 本身也是運算式：

```rust
let y = {
    let x = 3;
    x + 1       // 沒有分號，區塊值為 4
};
```

### 3.4 註解與文件註解

```rust
// 單行註解
/* 多行註解 */

/// 為下方項目撰寫文件（支援 Markdown）
fn documented() {}
```

### 3.5 控制流程

```rust
// if 是運算式
let n = 7;
let label = if n % 2 == 0 { "偶數" } else { "奇數" };

// loop：無窮迴圈，可用 break 回傳值
let mut counter = 0;
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2;
    }
};

// while
while counter > 0 {
    counter -= 1;
}

// for：最常用
for i in 0..5 {          // 0,1,2,3,4
    println!("{i}");
}
for i in (1..=3).rev() { // 3,2,1
    println!("{i}");
}
for item in [10, 20, 30] {
    println!("{item}");
}

// 迴圈標籤
'outer: for x in 0..5 {
    for y in 0..5 {
        if x * y > 6 { break 'outer; }
    }
}
```

### 3.6 輸出格式化

```rust
let name = "Ferris";
let pi = 3.14159;
println!("{}", name);            // 位置參數
println!("{name}");              // 行內
println!("{:.2}", pi);           // 3.14
println!("{:>8}", name);         // 靠右對齊，寬度 8
println!("{:?}", vec![1, 2]);    // Debug 格式
println!("{:#?}", vec![1, 2]);   // 美化 Debug
```
