# 7. 模式匹配與流程控制

### 7.1 `match`

`match` 必須**窮盡（exhaustive）**所有可能：

```rust
let n = 7;
match n {
    1 => println!("一"),
    2 | 3 => println!("二或三"),
    4..=9 => println!("四到九"),
    x if x < 0 => println!("負數 {x}"),   // 匹配守衛
    _ => println!("其他"),                // 萬用
}
```

### 7.2 `if let` 與 `let else`

```rust
let config: Option<u8> = Some(3);

// 只關心一種情況
if let Some(v) = config {
    println!("設定值 {v}");
}

// let else：匹配失敗則必須離開
fn parse(input: Option<&str>) -> i32 {
    let Some(s) = input else {
        return -1;
    };
    s.len() as i32
}
```

### 7.3 `while let`

```rust
let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("{top}");
}
```

### 7.4 解構

```rust
struct Point { x: i32, y: i32 }
let p = Point { x: 0, y: 7 };

match p {
    Point { x, y: 0 } => println!("在 x 軸上 {x}"),
    Point { x: 0, y } => println!("在 y 軸上 {y}"),
    Point { x, y } => println!("({x}, {y})"),
}
```
