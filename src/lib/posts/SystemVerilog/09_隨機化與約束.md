# 第 9 章　隨機化與約束

> 受約束的隨機測試 (Constrained Random Verification, CRV) 是 SV 驗證的核心：用少量程式碼產生大量有效且多樣的測試情境。

## 9.1 `rand` 與 `randc`

```systemverilog
class Packet;
  rand  bit [7:0] addr;
  rand  bit [7:0] data;
  randc bit [1:0] id;     // 循環隨機：用完所有值才重複
endclass

module tb;
  initial begin
    Packet p = new();
    repeat (5) begin
      if (!p.randomize()) $fatal("randomize failed");
      $display("addr=%0d data=%0d id=%0d", p.addr, p.data, p.id);
    end
  end
endmodule
```

⚠️ 一定要檢查 `randomize()` 的回傳值；約束衝突時它會回傳 0。

## 9.2 約束 (constraint)

```systemverilog
class Packet;
  rand bit [7:0]  addr;
  rand bit [15:0] len;
  rand bit [1:0]  kind;

  constraint c_addr  { addr inside {[8'h10:8'h7F]}; }
  constraint c_len   { len > 0; len <= 1024; }
  constraint c_align { addr[1:0] == 2'b00; }   // 4 位元組對齊
endclass
```

## 9.3 權重分布 `dist`

```systemverilog
constraint c_kind {
  kind dist { 0 := 70, 1 := 20, [2:3] :/ 10 };
}
```

- `:=`：每個值各得該權重
- `:/`：權重平均分配給範圍內所有值

上例 `[2:3] :/ 10` 表示 2 和 3 各佔 5。

## 9.4 條件約束

### 蘊含 `->`

```systemverilog
constraint c_imp {
  (kind == 0) -> len <= 64;      // kind 為 0 時，長度限制 64
}
```

### `if...else`

```systemverilog
constraint c_if {
  if (kind == 3) len inside {[512:1024]};
  else           len inside {[1:511]};
}
```

### 迭代約束

```systemverilog
rand bit [7:0] arr [8];
constraint c_sorted {
  foreach (arr[i]) if (i > 0) arr[i] > arr[i-1];
}
constraint c_unique { unique {arr}; }
```

## 9.5 求解順序 `solve ... before`

```systemverilog
constraint c_order {
  solve kind before len;      // 先決定 kind，再決定 len
}
```

只影響分布，不改變合法解集合。

## 9.6 行內約束 `randomize() with`

```systemverilog
p.randomize() with { addr == 8'h20; len < 16; };
```

可在不修改類別的情況下，針對單一測試加入額外約束。

## 9.7 控制隨機化

```systemverilog
p.rand_mode(0);               // 關閉所有 rand 變數的隨機化
p.addr.rand_mode(1);          // 只開啟 addr
p.c_len.constraint_mode(0);   // 關閉特定約束
```

## 9.8 `pre_randomize` / `post_randomize`

```systemverilog
class Packet;
  rand bit [7:0] data;
  bit parity;

  function void post_randomize();
    parity = ^data;           // 隨機化後計算同位元
  endfunction
endclass
```

## 9.9 `std::randomize` 與 `$urandom`

```systemverilog
int x;
std::randomize(x) with { x inside {[1:10]}; };

int r = $urandom_range(10, 1);   // 1~10 的隨機數
```

## 9.10 種子 (Seed) 與可重現性

模擬器通常提供命令列種子選項（如 `+ntb_random_seed=123`，依工具而異）。發現 bug 時，**記下種子**才能重現相同的隨機序列。

## 9.11 範例：隨機化交易包

```systemverilog
class AxiLite;
  rand bit        write;
  rand bit [31:0] addr;
  rand bit [31:0] data;

  constraint c_addr  { addr inside {[32'h0000_0000:32'h0000_0FFF]}; addr[1:0]==0; }
  constraint c_dist  { write dist {1 := 6, 0 := 4}; }
  constraint c_rd    { !write -> data == 0; }
endclass
```

## 練習

1. 建立封包類別：`len` 在 1~64，`payload` 為長度 `len` 的動態陣列（`rand bit [7:0] payload[]`，約束 `payload.size() == len`）。
2. 讓 `addr` 有 80% 機率落在 `[0:15]`，20% 落在 `[16:255]`。
3. 用 `randomize() with` 讓某次測試只產生 `write == 1` 且 `addr` 為偶數的交易。
4. 故意寫出互相衝突的約束，觀察 `randomize()` 的行為。
