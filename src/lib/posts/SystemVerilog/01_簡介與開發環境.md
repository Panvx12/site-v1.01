# 第 1 章　簡介與開發環境

## 1.1 SystemVerilog 是什麼？

SystemVerilog（SV）是 IEEE 1800 標準定義的**硬體描述與驗證語言 (HDVL)**，是 Verilog (IEEE 1364) 的超集 (superset)。

| 面向 | 內容 |
|------|------|
| 硬體設計 | `logic`、`always_ff`/`always_comb`、`interface`、`package`、`enum`、`struct` |
| 驗證 | `class`、隨機化與約束、斷言 (SVA)、功能覆蓋率、`mailbox`/`semaphore` |
| 整合 | DPI-C（與 C 語言互通）、UVM 方法學是建立在 SV 之上 |

**重點**：SV 同時涵蓋「可合成的設計」與「不可合成、僅供模擬的驗證程式碼」。寫程式時要清楚自己寫的是哪一種。

## 1.2 模擬流程

```
原始碼 (.sv) → 編譯 (compile) → 展開 (elaborate) → 模擬 (simulate) → 波形 / log
```

- **編譯**：語法檢查
- **展開**：建立階層、解析 parameter、連接埠
- **模擬**：事件驅動 (event-driven)，依時間推進執行

## 1.3 常用工具

| 工具 | 類型 | 備註 |
|------|------|------|
| EDA Playground | 線上、免安裝 | 最適合入門，可選 Questa/VCS/Xcelium 等 |
| Icarus Verilog | 開源 | 只支援部分 SV（設計語法為主），不支援完整 class/隨機化 |
| Verilator | 開源 | 速度快，支援可合成 SV 與部分驗證語法，較新版本支援 `--timing` |
| Questa / VCS / Xcelium | 商用 | 完整支援，業界使用 |
| GTKWave | 開源 | 查看 VCD/FST 波形 |

## 1.4 第一個程式

檔名：`hello.sv`

```systemverilog
module hello;
  initial begin
    $display("Hello, SystemVerilog!");
  end
endmodule
```

### 執行方式

```bash
# Icarus Verilog
iverilog -g2012 -o hello hello.sv
vvp hello

# Verilator（5.x 以上）
verilator --binary --timing hello.sv
./obj_dir/Vhello
```

## 1.5 基本語法規則

- 區分大小寫
- 敘述以分號 `;` 結尾
- 註解：`// 單行`、`/* 多行 */`
- 區塊用 `begin ... end`（單一敘述可省略）
- 數字格式：`<位元寬>'<進位><數值>`，例：`8'hFF`、`4'b1010`、`16'd100`
- 常用系統工作 (system task)：`$display`、`$monitor`、`$time`、`$finish`、`$random`

```systemverilog
module syntax_demo;
  logic [7:0] a;
  initial begin
    a = 8'hA5;
    $display("a = %h (hex), %b (bin), %0d (dec)", a, a, a);
    #10;                       // 延遲 10 個時間單位
    $display("time = %0t", $time);
    $finish;
  end
endmodule
```

## 1.6 `timescale`

```systemverilog
`timescale 1ns/1ps   // 時間單位 1ns，精度 1ps
```

⚠️ 若多個檔案 `timescale` 不一致或缺漏，可能造成延遲數值意外。建議每個檔案都明確寫出。

## 練習

1. 在你的環境中成功執行 `hello.sv`。
2. 宣告一個 16 位元的 `logic` 變數，賦值 `16'hBEEF`，用 `%h`、`%b`、`%d` 印出。
3. 用 `#5` 延遲後再印出 `$time`，觀察 `timescale` 對結果的影響。
