# 第 3 章　模組、埠與參數化

## 3.1 模組宣告（ANSI 風格）

```systemverilog
module adder #(
  parameter int WIDTH = 8
) (
  input  logic [WIDTH-1:0] a,
  input  logic [WIDTH-1:0] b,
  output logic [WIDTH:0]   sum
);
  assign sum = a + b;
endmodule
```

- `#( ... )`：參數列表
- 埠方向：`input`、`output`、`inout`
- 埠型別建議一律用 `logic`

## 3.2 實例化 (Instantiation)

```systemverilog
module top;
  logic [7:0] x, y;
  logic [8:0] z;

  // 具名連接（推薦）
  adder #(.WIDTH(8)) u_add (.a(x), .b(y), .sum(z));

  // 同名自動連接：埠名與訊號名相同時
  // adder #(.WIDTH(8)) u_add2 (.*);
endmodule
```

| 連接方式 | 語法 | 建議 |
|----------|------|------|
| 位置連接 | `adder u(x,y,z)` | 容易接錯，不建議 |
| 具名連接 | `.a(x)` | 推薦 |
| 隱含同名 | `.a` | 簡潔 |
| 萬用 | `.*` | 埠多且同名時方便 |

## 3.3 參數：`parameter` 與 `localparam`

```systemverilog
module fifo #(
  parameter int DEPTH = 16,
  parameter int WIDTH = 8
) (/* ... */);
  localparam int ADDR_W = $clog2(DEPTH);   // 內部計算，不可從外部覆寫
endmodule
```

- `parameter`：可由實例化時覆寫
- `localparam`：僅模組內部使用
- `$clog2(N)`：向上取整的 log2，常用於計算位址寬度

## 3.4 `generate`

### for-generate：重複實例

```systemverilog
module reg_array #(parameter int N = 4)(
  input  logic clk,
  input  logic [7:0] d [N],
  output logic [7:0] q [N]
);
  genvar i;
  generate
    for (i = 0; i < N; i++) begin : g_reg
      always_ff @(posedge clk) q[i] <= d[i];
    end
  endgenerate
endmodule
```

### if-generate：條件編譯結構

```systemverilog
module wrapper #(parameter bit FAST = 1)(/*...*/);
  generate
    if (FAST) begin : g_fast
      // 快速版本
    end else begin : g_small
      // 省面積版本
    end
  endgenerate
endmodule
```

## 3.5 `package` 與 `import`

```systemverilog
package my_pkg;
  typedef enum logic [1:0] {READ, WRITE, IDLE} cmd_t;
  parameter int BUS_W = 32;

  function automatic int max(int a, int b);
    return (a > b) ? a : b;
  endfunction
endpackage

module use_pkg;
  import my_pkg::*;          // 引入全部
  cmd_t c = WRITE;
  initial $display("%s, %0d", c.name(), max(3, 7));
endmodule
```

也可以用 `my_pkg::cmd_t` 的完整名稱而不 import。

## 3.6 巨集與 include

```systemverilog
`define DATA_W 16
`include "defs.svh"
`ifdef DEBUG
  // 除錯程式碼
`endif
```

⚠️ 巨集是**文字取代**、無範圍與型別檢查；能用 `parameter`/`package` 解決的就別用 `` `define ``。

## 3.7 `function` 與 `task`（簡介）

```systemverilog
function automatic int square(int x);
  return x * x;
endfunction
```

- `function`：不可耗時（不能有 `#`、`@`、`wait`）、有回傳值
- `task`：可耗時、無回傳值（可用 output 參數）
- 詳見第 7 章

## 練習

1. 寫一個參數化的 `N` 位元 2-to-1 多工器，並實例化為 8 位元與 16 位元兩個版本。
2. 用 `generate for` 建立 N 位元漣波進位加法器（以 1 位元全加器串接）。
3. 建立 `package`，放入 opcode 的 `enum`，並在兩個模組中共用。
