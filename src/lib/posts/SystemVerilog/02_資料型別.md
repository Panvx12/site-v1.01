# 第 2 章　資料型別

## 2.1 四態與二態

- **四態 (4-state)**：0、1、X（未知）、Z（高阻）
- **二態 (2-state)**：只有 0、1（模擬較快，但無法表示 X/Z）

| 型別 | 態數 | 寬度 | 有號 | 說明 |
|------|------|------|------|------|
| `logic` | 4 | 自訂 | 否 | 最常用，取代 `reg`/`wire` 的多數用途 |
| `reg` / `wire` | 4 | 自訂 | 否 | Verilog 舊式 |
| `bit` | 2 | 自訂 | 否 | 常用於 testbench |
| `byte` | 2 | 8 | 是 | |
| `shortint` | 2 | 16 | 是 | |
| `int` | 2 | 32 | 是 | 迴圈變數常用 |
| `longint` | 2 | 64 | 是 | |
| `integer` | 4 | 32 | 是 | Verilog 舊式 |

```systemverilog
module types_demo;
  logic [7:0] data;      // 4 態 8 位元
  bit   [3:0] cnt;       // 2 態 4 位元
  int         i;         // 32 位元有號
  logic signed [7:0] s;  // 有號 8 位元

  initial begin
    data = 8'bxxxx_0001;
    $display("data = %b", data);   // 保留 x
    cnt  = 4'd15;
    cnt  = cnt + 1;                // 溢位回到 0
    $display("cnt = %0d", cnt);
  end
endmodule
```

### `logic` 的優點

`logic` 可同時用於 `assign` 與 `always` 區塊中驅動，但**同一個 `logic` 變數不能有多個驅動來源**（多重驅動需用 `wire`）。

## 2.2 陣列

### Packed 陣列（位元向量）

維度寫在變數名**前**，在記憶體中連續排列，可視為一個大向量。

```systemverilog
logic [3:0][7:0] word;   // 4 個 byte，共 32 位元
initial begin
  word = 32'hDEAD_BEEF;
  $display("%h", word[3]);  // DE
  $display("%h", word[0]);  // EF
end
```

### Unpacked 陣列（記憶體）

維度寫在變數名**後**。

```systemverilog
logic [7:0] mem [0:15];   // 16 個 8 位元元素
logic [7:0] mem2 [16];    // 等價簡寫
initial begin
  foreach (mem[i]) mem[i] = i * 2;
end
```

### 動態陣列 (Dynamic Array)

```systemverilog
int arr[];
initial begin
  arr = new[5];          // 配置 5 個元素
  arr = '{1,2,3,4,5};
  arr = new[10](arr);    // 擴充並保留舊內容
  $display("size = %0d", arr.size());
  arr.delete();
end
```

### 佇列 (Queue)

```systemverilog
int q[$];
initial begin
  q.push_back(10);
  q.push_back(20);
  q.push_front(5);               // {5,10,20}
  $display("%0d", q.pop_front()); // 5
  $display("size=%0d", q.size());
  q.insert(1, 99);               // 在 index 1 插入
  q.delete(0);                   // 刪除 index 0
end
```

### 關聯陣列 (Associative Array)

```systemverilog
int score[string];
initial begin
  score["Alice"] = 90;
  score["Bob"]   = 75;
  if (score.exists("Alice")) $display("Alice=%0d", score["Alice"]);
  foreach (score[name]) $display("%s -> %0d", name, score[name]);
end
```

### 常用陣列方法

`size()`、`sum()`、`min()`、`max()`、`sort()`、`rsort()`、`reverse()`、`shuffle()`、`find()`

```systemverilog
int a[] = '{5, 3, 8, 1};
initial begin
  a.sort();
  $display("%p", a);            // '{1, 3, 5, 8}
  $display("sum=%0d", a.sum());
end
```

## 2.3 `enum`（列舉）

```systemverilog
typedef enum logic [1:0] {IDLE, RUN, DONE, ERR} state_t;
state_t st;

initial begin
  st = RUN;
  $display("st = %s (%0d)", st.name(), st);   // RUN (1)
  st = st.next();                              // DONE
end
```

`enum` 方法：`first()`、`last()`、`next()`、`prev()`、`num()`、`name()`。

⚠️ 不能直接把整數賦值給 enum，需用 cast：`st = state_t'(2);`

## 2.4 `struct`（結構）

```systemverilog
typedef struct packed {
  logic [7:0] addr;
  logic [7:0] data;
  logic       we;
} bus_t;

bus_t b;
initial begin
  b = '{addr: 8'h10, data: 8'hFF, we: 1'b1};
  $display("addr=%h data=%h we=%b", b.addr, b.data, b.we);
  $display("total bits = %0d", $bits(b));   // 17
end
```

- `struct packed`：可合成、可當向量使用
- 非 packed struct：多用於 testbench

## 2.5 `typedef` 與 `string`

```systemverilog
typedef logic [15:0] word_t;
word_t w;

string s = "hello";
initial begin
  s = {s, " world"};
  $display("%s, len=%0d", s, s.len());
  $display("%s", s.toupper());
end
```

## 2.6 型別轉換 (Casting)

```systemverilog
int i = 300;
byte b = byte'(i);           // 截斷
logic [7:0] u = 8'(i);       // 寬度轉換
real r = real'(i) / 7.0;
int  n = int'(-5);           // 轉為有號 int
logic signed [7:0] sv = signed'(8'hFF);   // 轉為有號：-1
```
