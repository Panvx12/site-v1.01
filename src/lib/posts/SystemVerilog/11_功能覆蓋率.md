# 第 11 章　功能覆蓋率 (Functional Coverage)

> 「測完了嗎？」程式碼覆蓋率只告訴你哪些行被執行；**功能覆蓋率**則告訴你規格要求的各種情境是否都被測過。

## 11.1 覆蓋率的種類

| 類型 | 來源 | 說明 |
|------|------|------|
| 程式碼覆蓋率 | 工具自動收集 | line、branch、toggle、FSM、condition |
| 功能覆蓋率 | **工程師撰寫** | covergroup、coverpoint、cross |
| 斷言覆蓋率 | `cover property` | 時序情境是否出現 |

## 11.2 基本 covergroup

```systemverilog
module tb;
  logic [7:0] addr;
  logic       write;

  covergroup cg @(posedge clk);
    cp_addr: coverpoint addr {
      bins low  = {[0:63]};
      bins mid  = {[64:191]};
      bins high = {[192:255]};
    }
    cp_write: coverpoint write;
  endgroup

  cg cg_inst = new();
endmodule
```

- `covergroup`：覆蓋率的容器，可以用 `@(事件)` 自動取樣
- `coverpoint`：要觀察的變數或運算式
- `bins`：把值分成幾個「桶」，每桶被命中一次就算覆蓋

## 11.3 Bins 的寫法

```systemverilog
coverpoint len {
  bins zero     = {0};
  bins small[]  = {[1:4]};          // 各自獨立的 bin：1、2、3、4
  bins medium   = {[5:16]};
  bins large    = {[17:$]};
  bins others[] = default;
  illegal_bins bad = {255};         // 出現即報錯
  ignore_bins  skip = {128};        // 不計入
}
```

轉換 (transition) bins：

```systemverilog
coverpoint state {
  bins idle_to_run = (IDLE => RUN);
  bins run_seq     = (IDLE => RUN => DONE);
}
```

## 11.4 Cross（交叉覆蓋）

```systemverilog
covergroup cg;
  cp_addr:  coverpoint addr  { bins a[4] = {[0:255]}; }
  cp_write: coverpoint write;
  x_aw:     cross cp_addr, cp_write;   // 所有位址區 × 讀/寫 組合
endgroup
```

排除不合理組合：

```systemverilog
x_aw: cross cp_addr, cp_write {
  ignore_bins no_write_hi = binsof(cp_addr.a[3]) && binsof(cp_write) intersect {1};
}
```

## 11.5 手動取樣 `sample()`

自動取樣不夠彈性時，在 class 中常搭配 `sample()` 使用：

```systemverilog
class Coverage;
  Transaction t;

  covergroup cg;
    cp_addr: coverpoint t.addr { bins b[4] = {[0:255]}; }
    cp_kind: coverpoint t.kind;
    cross cp_addr, cp_kind;
  endgroup

  function new();
    cg = new();
  endfunction

  function void sample(Transaction tr);
    t = tr;
    cg.sample();
  endfunction
endclass
```

## 11.6 選項與查詢

```systemverilog
covergroup cg;
  option.per_instance = 1;
  option.goal         = 100;
  option.comment      = "bus coverage";
  // ...
endgroup

initial begin
  // ... 跑模擬
  $display("coverage = %0.2f%%", cg_inst.get_inst_coverage());
end
```

## 11.7 覆蓋率驅動驗證 (CDV) 流程

```
撰寫驗證計畫 → 定義 covergroup → 跑隨機測試 → 檢視覆蓋率報告
      ↑                                              │
      └──── 加強約束 / 新增 directed test ←──────────┘
```

1. 從規格拆出「必須驗證的特性」
2. 轉為 covergroup / cross
3. 跑大量隨機測試並合併多次結果
4. 分析**漏洞 (hole)**，調整約束或補測試
5. 目標：功能覆蓋率達標（常見目標 100%，扣除合理排除項）
