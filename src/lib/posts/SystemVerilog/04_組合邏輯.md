# 第 4 章　組合邏輯

## 4.1 兩種描述方式

### `assign`（連續賦值）

```systemverilog
assign y = a & b;
assign z = sel ? a : b;
```

### `always_comb`

```systemverilog
always_comb begin
  y = a & b;
end
```

`always_comb` 的優點（相較 `always @(*)`）：

- 自動推導敏感列表（包含函式內讀取的訊號）
- 時間 0 會自動執行一次
- 工具會檢查是否意外產生 latch、是否有多重驅動

## 4.2 賦值運算子

| 運算子 | 名稱 | 使用場合 |
|--------|------|----------|
| `=` | 阻塞 (blocking) | 組合邏輯 `always_comb` |
| `<=` | 非阻塞 (non-blocking) | 時序邏輯 `always_ff` |

**黃金規則**：組合邏輯用 `=`，時序邏輯用 `<=`，不要混用。

## 4.3 `if` 與 `case`

### 4:1 多工器

```systemverilog
module mux4 (
  input  logic [7:0] d0, d1, d2, d3,
  input  logic [1:0] sel,
  output logic [7:0] y
);
  always_comb begin
    case (sel)
      2'b00:   y = d0;
      2'b01:   y = d1;
      2'b10:   y = d2;
      2'b11:   y = d3;
      default: y = '0;
    endcase
  end
endmodule
```

### 解碼器

```systemverilog
module dec3to8 (
  input  logic [2:0] in,
  input  logic       en,
  output logic [7:0] out
);
  always_comb begin
    out = '0;                // 先給預設值
    if (en) out[in] = 1'b1;
  end
endmodule
```

## 4.4 避免 Latch

若 `always_comb` 中某條件路徑沒有對輸出賦值，會推導出鎖存器 (latch)。

```systemverilog
// ❌ 錯誤：en=0 時 y 保持舊值 → latch
always_comb begin
  if (en) y = a;
end

// ✅ 正確：給預設值
always_comb begin
  y = '0;
  if (en) y = a;
end
```

⚠️ 好習慣：**在 always_comb 開頭先對所有輸出賦預設值**。

## 4.5 `unique` 與 `priority`

```systemverilog
// unique：各分支互斥且涵蓋所有情況，不符合時模擬器報警告
always_comb begin
  unique case (sel)
    2'b00: y = a;
    2'b01: y = b;
    2'b10: y = c;
    2'b11: y = d;
  endcase
end

// priority：依序判斷，至少一個分支成立
always_comb begin
  priority if (req[0])      gnt = 3'b001;
  else if (req[1])          gnt = 3'b010;
  else if (req[2])          gnt = 3'b100;
  else                      gnt = 3'b000;
end
```

## 4.6 `casez` 與 `inside`

```systemverilog
// 優先權編碼器：z/? 當萬用字元
always_comb begin
  casez (req)
    4'b1???: idx = 3;
    4'b01??: idx = 2;
    4'b001?: idx = 1;
    4'b0001: idx = 0;
    default: idx = 0;
  endcase
end

// inside：集合成員判斷
if (opcode inside {8'h01, 8'h02, [8'h10:8'h1F]}) ...
```

## 4.7 範例：簡易 ALU

```systemverilog
module alu (
  input  logic [7:0] a, b,
  input  logic [2:0] op,
  output logic [7:0] y,
  output logic       zero
);
  always_comb begin
    unique case (op)
      3'd0: y = a + b;
      3'd1: y = a - b;
      3'd2: y = a & b;
      3'd3: y = a | b;
      3'd4: y = a ^ b;
      3'd5: y = a << 1;
      3'd6: y = a >> 1;
      default: y = '0;
    endcase
    zero = (y == '0);
  end
endmodule
```

## 練習

1. 實作 8-to-3 優先權編碼器（用 `casez`），並輸出 `valid`。
2. 實作 4 位元比較器，輸出 `lt / eq / gt`。
3. 故意寫出會產生 latch 的程式，觀察模擬器 / 合成器警告，再修正。
