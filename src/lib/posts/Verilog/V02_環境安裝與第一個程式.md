## 2.1 你需要哪些工具？

| 工具 | 用途 | 比喻 |
|------|------|------|
| **Icarus Verilog** (`iverilog`、`vvp`) | 把 Verilog 編譯並模擬 | 電路的「實驗台」 |
| **GTKWave** | 把模擬結果畫成波形圖 | 電路的「示波器」 |
| 文字編輯器（VS Code 等） | 寫程式 | 筆記本 |

## 2.2 安裝（依你的系統挑一種）

### 方案 A：Windows（建議用 WSL）

1. 在 Windows 安裝 **WSL**（Windows 的 Linux 子系統），開啟 Ubuntu
2. 在 Ubuntu 輸入：

```bash
sudo apt update
sudo apt install iverilog gtkwave
```

> 也可以下載 **OSS CAD Suite**（一包裝好所有開源硬體工具），解壓縮後把資料夾加進 PATH 即可。

### 方案 B：Ubuntu / Debian

```bash
sudo apt update
sudo apt install iverilog gtkwave
```

### 方案 C：macOS（需先有 Homebrew）

```bash
brew install icarus-verilog
brew install --cask gtkwave
```

### 方案 D：先不安裝，用線上工具

打開 **EDA Playground**（瀏覽器），語言選 Verilog，模擬器選 Icarus Verilog，可直接貼程式並執行。學完前幾章再安裝本機版也沒問題。

## 2.5 第一個程式：Hello, Verilog!

用編輯器建立檔案 `hello.v`：

```verilog
module hello;
  initial begin
    $display("Hello, Verilog!");
    $finish;
  end
endmodule
```

### 逐行解說

| 行 | 意思 |
|----|------|
| `module hello;` | 宣告一個叫 `hello` 的模組（電路盒子）。`;` 結尾 |
| `initial begin` | 「模擬一開始就執行」的區塊。`begin` 是區塊開始 |
| `$display("...");` | 在螢幕上印出文字（類似 C 的 `printf`），自動換行 |
| `$finish;` | 結束模擬。沒寫的話模擬器可能一直等下去 |
| `end` | 結束 `initial` 的區塊 |
| `endmodule` | 結束模組。**這行後面不加分號** |

💡 `$` 開頭的是**系統工作 (system task)**，是模擬器內建的功能，不是電路。

⚠️ `initial` 區塊只用在**模擬**，不是真正的電路（後面第 13 章會說明）。

## 2.6 編譯與執行：兩個指令

```bash
iverilog -g2005 -o hello.vvp hello.v
vvp hello.vvp
```

| 指令 | 做什麼 |
|------|--------|
| `iverilog -g2005 -o hello.vvp hello.v` | **編譯**：檢查語法，輸出可執行檔 `hello.vvp` |
| `vvp hello.vvp` | **執行**模擬 |

選項解釋：

- `-g2005`：使用 Verilog-2005 語法
- `-o hello.vvp`：輸出檔案取名 `hello.vvp`（`o` = output）
- `hello.v`：要編譯的原始碼

### 預期輸出

```
Hello, Verilog!
```

可能會在下面多一行 `$finish called at ...` 之類的訊息，這是正常的。

```
 hello.v ──► iverilog (編譯) ──► hello.vvp ──► vvp (執行) ──► 螢幕輸出
```

## 2.7 🧪 動手做 + 讀懂錯誤訊息

### 實驗 1：故意拿掉分號

把 `$display("Hello, Verilog!")` 後面的 `;` 刪掉，再編譯：

```bash
iverilog -g2005 -o hello.vvp hello.v
```

你會看到類似這樣的錯誤（實際文字依版本略有不同）：

```
hello.v:4: syntax error
hello.v:4: error: malformed statement
```

**怎麼讀**：

- `hello.v:4` → 檔案 `hello.v` 的**第 4 行**附近有問題
- `syntax error` → 語法錯誤

💡 技巧：編譯器指出的行號，**問題常常在那一行的上一行**（例如上一行少了分號）。

### 實驗 2：拿掉 `$finish`

模擬可能不會自己結束，按 `Ctrl+C` 中斷。這就是為什麼 testbench 都要有 `$finish`。

### 實驗 3：改成印出算式

```verilog
module hello;
  initial begin
    $display("3 + 4 = %0d", 3 + 4);
    $finish;
  end
endmodule
```

預期輸出：`3 + 4 = 7`。

`%0d` 是格式符號，意思是「把這個值用十進位印出來」，`0` 代表不要補空白。常用格式：

| 格式 | 意思 | 例 |
|------|------|----|
| `%d` / `%0d` | 十進位 | 7 |
| `%b` | 二進位 | 0111 |
| `%h` | 十六進位 | 7 |
| `%s` | 字串 | Hello |

## 2.8 常見環境問題

| 症狀 | 可能原因 | 解法 |
|------|---------|------|
| `iverilog: command not found` | 沒安裝或沒加入 PATH | 重新安裝；Windows 用 WSL 最省事 |
| `No such file or directory` | 目前所在資料夾不對 | 用 `pwd` 看位置、`ls` 看檔案 |
| 編譯出現 `syntax error` | 少分號、少 `end` | 看行號，檢查那行與上一行 |
| `Unknown module type` | 模組名稱打錯，或忘了把該檔案一起編譯 | 檢查拼字、編譯指令中是否列出所有 `.v` |
| 中文亂碼 | 檔案編碼 | 檔案存成 UTF-8；程式內的字串盡量用英文 |

## 2.9 Verilog 基本語法規則（先認識）

- **區分大小寫**：`Clk` 和 `clk` 是不同東西
- 每個敘述以 `;` 結尾
- 註解：`// 單行註解`、`/* 多行註解 */`
- 多個敘述用 `begin ... end` 包起來（像 C 的 `{ }`）
- 名稱用英文字母、數字、底線，**不能數字開頭**

## 本章小結

- 工具：`iverilog`（編譯）→ `vvp`（執行）→ `gtkwave`（看波形）
- 每個設計都包在 `module ... endmodule` 裡
- `initial` + `$display` + `$finish` 可以讓你快速做實驗
- 看錯誤訊息：先看**行號**，再看**錯誤種類**，問題常在上一行

## 小測驗

**Q1.** `iverilog` 和 `vvp` 各負責什麼？

<details><summary>看答案</summary>

`iverilog` 負責**編譯**（檢查語法並產生可執行檔），`vvp` 負責**執行**模擬。
</details>

**Q2.** 編譯錯誤說 `hello.v:6: syntax error`，你應該先檢查哪裡？

<details><summary>看答案</summary>

先檢查**第 6 行**，也要看**第 5 行**（上一行可能少了分號或 `end`）。
</details>

**Q3.** 為什麼 `endmodule` 後面不用加分號？

<details><summary>看答案</summary>

`endmodule` 是**結束關鍵字**，不是一般敘述。`end`、`endcase`、`endmodule` 這類 `end` 開頭的關鍵字都不加分號。
</details>

## 練習

1. 讓程式印出你的名字（英文）。
2. 印出 `8'hFF` 的十進位與二進位：`$display("%0d %b", 8'hFF, 8'hFF);`（預期：`255 11111111`）。
3. 在 `$display` 前加 `#10;`（延遲 10 個時間單位）再印出，觀察有沒有差別。（下一章會解釋時間。）
