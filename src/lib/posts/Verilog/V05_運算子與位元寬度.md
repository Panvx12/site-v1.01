# 第 5 章　運算子與位元寬度

## 學習目標

- 會用算術、比較、位元、邏輯、縮減、移位等運算子
- **分清楚 `&` 和 `&&`、`|` 和 `||`、`~` 和 `!`**（新手最大陷阱）
- 理解位元寬度如何影響結果（溢位、進位）
- 會用條件運算子 `? :` 做選擇

---

## 5.1 運算子總覽

| 類別 | 運算子 | 說明 |
|------|--------|------|
| 算術 | `+  -  *  /  %` | 加減乘除餘數 |
| 比較 | `<  <=  >  >=` | 大小比較，結果是 1 位元 |
| 相等 | `==  !=` | 相等、不相等 |
| 位元運算 | `&  \|  ^  ~` | 對每個位元分別運算 |
| 邏輯運算 | `&&  \|\|  !` | 把整個值當成「真/假」 |
| 縮減運算 | `&a  \|a  ^a` | 把一個向量的所有位元縮成 1 位元 |
| 移位 | `<<  >>` | 左移、右移 |
| 條件 | `? :` | 二選一 |
| 連接 | `{ }` | 拼接（第 4 章） |

## 5.2 位元運算 vs 邏輯運算（重要！）

這兩組長得很像，但意思不同，**新手超容易寫錯**。

| | 位元運算（bitwise） | 邏輯運算（logical） |
|---|--------------------|--------------------|
| AND | `&` | `&&` |
| OR | `\|` | `\|\|` |
| NOT | `~` | `!` |
| 對象 | **每個位元各自運算** | **整個值當成真或假** |
| 結果 | 跟輸入一樣寬 | **只有 1 位元** |

### 規則

- Verilog 裡，**不是 0 的值就是「真」，全是 0 才是「假」**
- 邏輯運算 `&&`、`||`、`!` 用在條件判斷（例如 `if`）
- 位元運算 `&`、`|`、`~` 用在資料運算

### 實驗

```verilog
module logic_demo;
  reg [3:0] a, b;

  initial begin
    a = 4'b1010;
    b = 4'b0101;

    $display("a & b  = %b", a & b);
    $display("a && b = %b", a && b);
    $display("a | b  = %b", a | b);
    $display("a || b = %b", a || b);
    $display("~a     = %b", ~a);
    $display("!a     = %b", !a);
    $finish;
  end
endmodule
```

### 預期輸出

```
a & b  = 0000
a && b = 1
a | b  = 1111
a || b = 1
~a     = 0101
!a     = 0
```

### 為什麼？

```
a     = 1010
b     = 0101
a & b = 0000    ← 每一位各自 AND：全是 0
a | b = 1111    ← 每一位各自 OR：全是 1
~a    = 0101    ← 每一位各自反相

a && b：a 不是 0（真），b 不是 0（真），真 AND 真 = 1
!a    ：a 不是 0（真），NOT 真 = 0
```

💡 **口訣：寫硬體資料用單個符號 `& | ~`，寫 `if (...)` 條件用雙符號 `&& || !`。**

```verilog
if (a && b) ...         // ✅ 條件判斷：「a 和 b 都成立」
y = a & b;              // ✅ 資料運算：位元 AND
```

## 5.3 算術運算與位元寬度

### 基本

```verilog
y = a + b;
y = a - b;
y = a * 2;
y = a / 4;       // 除法（模擬可以，硬體上很貴，少用）
y = a % 10;      // 餘數
```

### 溢位：放不下就繞回去

```verilog
module overflow_demo;
  reg [7:0] a, b;
  reg [7:0] sum8;      // 8 位元的結果
  reg [8:0] sum9;      // 9 位元的結果

  initial begin
    a = 8'd200;
    b = 8'd100;
    sum8 = a + b;
    sum9 = a + b;
    $display("sum8 = %0d", sum8);
    $display("sum9 = %0d", sum9);
    $finish;
  end
endmodule
```

預期輸出：

```
sum8 = 44
sum9 = 300
```

**原因**：200 + 100 = 300，8 位元最大 255 放不下，只留低 8 位：300 − 256 = **44**。把結果放進 **9 位元**的變數就不會丟掉進位。

💡 比喻：8 位元像只有 3 格的里程表，999 再加 1 會變 000。

### 保留進位的標準寫法

```verilog
wire [7:0] a, b;
wire [7:0] sum;
wire       carry;

assign {carry, sum} = a + b;      // 左邊拼成 9 位元，進位進到 carry
```

規則：**運算結果會被放進「左邊」那麼寬的空間；左邊不夠寬就截掉高位。** 所以要保留進位，左邊就要多留 1 位元。

### 減法

```verilog
a = 8'd3;
b = 8'd5;
y = a - b;       // 若 y 是 8 位元 → 3 - 5 = -2 → 繞回 254
```

沒有負數（預設無號數）時，減法結果若小於 0 會「繞回」大數字。

## 5.4 比較與相等

```verilog
a < b       // 結果 1 位元：成立 1，不成立 0
a >= b
a == b
a != b
```

```verilog
assign is_zero = (a == 8'd0);
assign gt      = (a > b);
```

⚠️ 要小心：`=` 是賦值，`==` 才是比較。`assign y = (a == b);` 才是「判斷 a 是否等於 b」。

## 5.5 縮減運算

對**一個向量的所有位元**做同一種運算，縮成 1 位元。語法：運算子寫在**前面，沒有左邊的運算元**。

| 寫法 | 意義 |
|------|------|
| `&a` | 所有位元 AND：全是 1 才是 1 |
| `\|a` | 所有位元 OR：有任何一位是 1 就是 1 |
| `^a` | 所有位元 XOR：1 的個數是**奇數**就是 1（奇同位） |

```verilog
module reduce_demo;
  reg [3:0] a;
  initial begin
    a = 4'b1010;
    $display("&a = %b", &a);
    $display("|a = %b", |a);
    $display("^a = %b", ^a);
    $finish;
  end
endmodule
```

預期輸出：

```
&a = 0
|a = 1
^a = 0
```

`1010` 有 2 個 1（偶數個），所以 `^a` = 0；不是全 1，所以 `&a` = 0；有 1，所以 `|a` = 1。

用途：`|a` 可以判斷「是否非零」，`&a` 判斷「是否全 1」，`^a` 常用來算**同位元 (parity)**。

## 5.6 移位

```verilog
a << n      // 向左移 n 位，右邊補 0（相當於乘 2ⁿ）
a >> n      // 向右移 n 位，左邊補 0（相當於除 2ⁿ，無條件捨去）
```

```verilog
module shift_demo;
  reg [7:0] a;
  initial begin
    a = 8'b0000_1100;     // 12
    $display("a << 2 = %b (%0d)", a << 2, a << 2);
    $display("a >> 2 = %b (%0d)", a >> 2, a >> 2);
    $finish;
  end
endmodule
```

預期輸出：

```
a << 2 = 00110000 (48)
a >> 2 = 00000011 (3)
```

12 × 4 = 48、12 ÷ 4 = 3 ✓。

💡 移位在硬體裡**不用花任何電路**（只是改接線），所以用 `<< 1` 代替 `* 2` 很划算（工具通常也會自動最佳化）。

## 5.7 條件運算子 `? :`

```verilog
y = (條件) ? 值1 : 值2;
```

條件為真（非 0）選 `值1`，否則選 `值2`。**這就是多工器**：

```verilog
assign y = sel ? a : b;
```

```
        ┌─────┐
   a ──►│ 1   │
        │ MUX │──► y
   b ──►│ 0   │
        └──▲──┘
           │
          sel
```

可以串起來做多選一：

```verilog
assign y = (sel == 2'd0) ? d0 :
           (sel == 2'd1) ? d1 :
           (sel == 2'd2) ? d2 : d3;
```

## 5.8 運算順序

不確定誰先算時：**加括號**。

```verilog
y = a + b << 1;      // 先加還是先移位？很多人不確定
y = (a + b) << 1;    // ✅ 清楚
y = a + (b << 1);    // ✅ 清楚
```

大致順序（由高到低）：`! ~` → `* / %` → `+ -` → `<< >>` → `< <= > >=` → `== !=` → `&` → `^` → `|` → `&&` → `||` → `? :`。不用背，**多用括號**。

---

## 5.9 有號數（先知道有這回事）

預設所有數字是**無號數**。要有號數（可以負），要明確宣告：

```verilog
reg signed [7:0] s;      // 範圍 -128 ~ 127
```

本講義的練習**都用無號數**，等你熟悉後再深入有號運算。⚠️ 一個運算式中只要混到無號數，整個會被當成無號數處理，是常見的 bug 來源。

---

## 5.10 常見錯誤

| 錯誤 | 說明 | 解法 |
|------|------|------|
| 在 `if` 裡用 `&` | `if (a & b)` 在 1 位元時行得通，多位元會出奇怪結果 | 條件判斷用 `&&` |
| `=` 寫成 `==`（或反過來） | 賦值 vs 比較 | 看清楚 |
| 加法忘了留進位位元 | 結果被截斷 | 左邊多留 1 位元，用 `{carry, sum}` |
| 忘了加括號 | 順序和預期不同 | 括號用起來 |
| `!` 與 `~` 混用 | 一個 1 位元、一個逐位元 | 單一位元看情況；多位元請用 `~` 做反相 |

## 本章小結

- **資料用 `& | ~ ^`，條件用 `&& || !`**
- 結果放不下就**截掉高位**（溢位），要進位就多留一位元
- 縮減運算把向量縮成 1 位元（`&a`、`|a`、`^a`）
- `<<` 乘以 2ⁿ，`>>` 除以 2ⁿ
- `? :` 是多工器
- 不確定就加括號

## 小測驗

**Q1.** `a = 4'b1100, b = 4'b0011` 時，`a & b` 與 `a && b` 分別是？

<details><summary>看答案</summary>

`a & b` = `4'b0000`；`a && b`：兩個都非 0（真），結果 **1**。
</details>

**Q2.** `8'd250 + 8'd10` 放進 8 位元的變數，結果是多少？

<details><summary>看答案</summary>

260 − 256 = **4**。
</details>

**Q3.** `^4'b0111` 的結果？

<details><summary>看答案</summary>

`0111` 有 3 個 1（奇數個），所以 **1**。
</details>

**Q4.** `8'b0000_0101 << 3` 等於多少？

<details><summary>看答案</summary>

5 × 8 = 40 = **`8'b0010_1000`**。
</details>

**Q5.** 要把兩個 8 位元相加並保留進位，左邊該怎麼寫？

<details><summary>看答案</summary>

`assign {carry, sum} = a + b;`，其中 `carry` 是 1 位元、`sum` 是 8 位元。
</details>

## 練習

1. 預測並驗證：`4'd9 + 4'd9`，放進 4 位元與 5 位元變數，結果各是多少？（預期 2 與 18）
2. 寫一個模組：輸入 4 位元 `a`，輸出 `is_zero`（`a` 為 0 時為 1），分別用 `==` 和縮減運算 `~|a` 寫兩次。
3. 用 `^` 實作**偶同位元產生器**：輸入 7 位元資料，輸出 8 位元（原資料加上同位元，使 1 的總數為偶數）。
4. 用 `? :` 寫一個「取兩數較大者」`max2`：輸入 `a`、`b`（8 位元），輸出較大者。
