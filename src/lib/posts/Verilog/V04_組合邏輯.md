# 第 4 章　組合邏輯

## 4.1 兩種描述方式

### `assign`（連續賦值）

```verilog
assign y = a & b;
assign z = sel ? a : b;
```

- 左邊必須是 `wire`
- 右邊任何訊號改變就會重新計算（真正的「連線」）

### `always @(*)`

```verilog
reg y;
always @(*) begin
  y = a & b;
end
```

- `@(*)` 自動把區塊內讀取的所有訊號加入敏感列表（Verilog-2001）
- 左邊必須是 `reg`
- 使用 `@(*)` 而非手寫敏感列表，避免漏寫造成「模擬與合成結果不同」

⚠️ 不要寫 `always @(a or b)` 後又漏掉 `c`，這會讓模擬正常、合成結果卻不同。

## 4.2 賦值規則

| 運算子 | 名稱 | 用於 |
|--------|------|------|
| `=` | 阻塞賦值 (blocking) | 組合邏輯 `always @(*)` |
| `<=` | 非阻塞賦值 (non-blocking) | 時序邏輯 `always @(posedge clk)` |

**黃金規則**：組合邏輯用 `=`，時序邏輯用 `<=`，不要在同一個 always 混用。

## 4.3 `if` 與 `case`

### 4:1 多工器

```verilog
module mux4 (
  input  wire [7:0] d0, d1, d2, d3,
  input  wire [1:0] sel,
  output reg  [7:0] y
);
  always @(*) begin
    case (sel)
      2'b00:   y = d0;
      2'b01:   y = d1;
      2'b10:   y = d2;
      2'b11:   y = d3;
      default: y = 8'h00;
    endcase
  end
endmodule
```

### 3-to-8 解碼器

```verilog
module dec3to8 (
  input  wire [2:0] in,
  input  wire       en,
  output reg  [7:0] out
);
  always @(*) begin
    out = 8'b0;                 // 預設值
    if (en) out[in] = 1'b1;
  end
endmodule
```

## 4.4 避免 Latch

若組合邏輯的某些條件下輸出沒有被賦值，合成器會推導出**鎖存器 (latch)**。

```verilog
// ❌ 錯誤：en=0 時 y 保持舊值 → latch
always @(*) begin
  if (en) y = a;
end

// ✅ 正確方法一：else 補齊
always @(*) begin
  if (en) y = a;
  else    y = 1'b0;
end

// ✅ 正確方法二：先給預設值（推薦）
always @(*) begin
  y = 1'b0;
  if (en) y = a;
end
```

`case` 同理：務必有 `default`，或每個分支都對所有輸出賦值。

## 4.5 `casez` 與 `casex`

```verilog
// 優先權編碼器：? 與 z 當萬用字元
always @(*) begin
  casez (req)
    4'b1???: idx = 2'd3;
    4'b01??: idx = 2'd2;
    4'b001?: idx = 2'd1;
    default: idx = 2'd0;
  endcase
end
```

⚠️ 避免使用 `casex`：它會把 **X 也視為萬用字元**，可能讓模擬掩蓋真正的錯誤。需要萬用字元時用 `casez`。

## 4.6 範例集

### 全加器與進位保留

```verilog
module add8 (
  input  wire [7:0] a, b,
  input  wire       cin,
  output wire [7:0] sum,
  output wire       cout
);
  assign {cout, sum} = a + b + cin;
endmodule
```

### 比較器

```verilog
module cmp4 (
  input  wire [3:0] a, b,
  output wire       lt, eq, gt
);
  assign lt = (a <  b);
  assign eq = (a == b);
  assign gt = (a >  b);
endmodule
```

### ALU

```verilog
module alu (
  input  wire [7:0] a, b,
  input  wire [2:0] op,
  output reg  [7:0] y,
  output reg        zero
);
  always @(*) begin
    case (op)
      3'd0:    y = a + b;
      3'd1:    y = a - b;
      3'd2:    y = a & b;
      3'd3:    y = a | b;
      3'd4:    y = a ^ b;
      3'd5:    y = a << 1;
      3'd6:    y = a >> 1;
      default: y = 8'h00;
    endcase
    zero = (y == 8'h00);
  end
endmodule
```

### BCD 轉七段顯示（共陰極，輸出 `gfedcba`）

```verilog
module bcd7seg (
  input  wire [3:0] bcd,
  output reg  [6:0] seg
);
  always @(*) begin
    case (bcd)
      4'd0: seg = 7'b0111111;
      4'd1: seg = 7'b0000110;
      4'd2: seg = 7'b1011011;
      4'd3: seg = 7'b1001111;
      4'd4: seg = 7'b1100110;
      4'd5: seg = 7'b1101101;
      4'd6: seg = 7'b1111101;
      4'd7: seg = 7'b0000111;
      4'd8: seg = 7'b1111111;
      4'd9: seg = 7'b1101111;
      default: seg = 7'b0000000;
    endcase
  end
endmodule
```

## 4.7 組合邏輯迴圈

```verilog
// ❌ 組合迴圈：y 依賴自己
assign y = a & y;
```

合成工具通常會警告。組合邏輯中任何訊號都不應該（直接或間接）依賴自己的輸出。

## 4.8 檢查清單

- [ ] 組合 always 使用 `@(*)`
- [ ] 全部使用阻塞賦值 `=`
- [ ] 所有輸出在所有路徑都有賦值（預設值）
- [ ] `case` 有 `default`
- [ ] 沒有組合迴圈
- [ ] 一個訊號只被一個地方驅動

## 練習

1. 實作 8-to-3 優先權編碼器（用 `casez`），並輸出 `valid`。
2. 為 `alu` 寫 testbench，窮舉部分輸入並與參考運算比對。
