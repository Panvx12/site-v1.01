# 第 9 章　時序電路實作

## 學習目標

- 做出移位暫存器、邊緣偵測器、模 10 計數器、使能脈衝產生器、LED 閃爍器
- 學會用「使能脈衝」取代自己做新時脈（工程上最重要的習慣之一）
- 練習讀懂時序電路的預期波形

> 每個電路都依「規格 → 設計 → 驗證」。testbench 中的輸入都在**下降緣**改變（第 8 章）。

## 9.1 移位暫存器

### 規格

每個時脈，資料往左移一格，新資料 `din` 從最右邊進來。

```
        ┌───┬───┬───┬───┐
din ───►│ q0│ q1│ q2│ q3│   （此圖 q[0] 在最左只為示意）
        └───┴───┴───┴───┘
```

實際以向量表示：`q <= {q[N-2:0], din}`，也就是「把舊的 `q` 去掉最高位，再把 `din` 接到最右邊」。

### 設計

```verilog
module shift_reg #(parameter N = 4) (
  input  wire         clk,
  input  wire         rst_n,
  input  wire         din,
  output reg  [N-1:0] q
);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
      q <= {N{1'b0}};
    else
      q <= {q[N-2:0], din};
  end
endmodule
```

新語法：`#(parameter N = 4)` 是**參數**，讓模組可以改變寬度（第 12 章詳細說明）。`{N{1'b0}}` 是 N 個 0。

### Testbench

```verilog
`timescale 1ns/1ps
module tb_shift;
  reg        clk = 1'b0;
  reg        rst_n, din;
  wire [3:0] q;

  shift_reg #(.N(4)) dut (.clk(clk), .rst_n(rst_n), .din(din), .q(q));

  always #5 clk = ~clk;

  always @(negedge clk)
    $display("t=%0d q=%b", $time, q);

  initial begin
    rst_n = 1'b0; din = 1'b0;
    #22 rst_n = 1'b1;
    @(negedge clk) din = 1'b1;     // t=30
    @(negedge clk) din = 1'b0;     // t=40
    @(negedge clk) din = 1'b1;     // t=50
    @(negedge clk) din = 1'b1;     // t=60
    @(negedge clk) din = 1'b0;     // t=70
    repeat (2) @(negedge clk);     // t=80, 90
    #1 $finish;
  end
endmodule
```

### 預期輸出

```
t=10 q=0000
t=20 q=0000
t=30 q=0000
t=40 q=0001
t=50 q=0010
t=60 q=0101
t=70 q=1011
t=80 q=0110
t=90 q=1100
```

### 對照

送進去的 `din` 依序是 `1, 0, 1, 1, 0, 0`：

| 上升緣 | 讀到的 din | q（之後） |
|:------:|:---------:|:--------:|
| 35 | 1 | 0001 |
| 45 | 0 | 0010 |
| 55 | 1 | 0101 |
| 65 | 1 | 1011 |
| 75 | 0 | 0110（最高位的 1 被擠出去） |
| 85 | 0 | 1100 |

💡 用途：串列轉並列（序列資料收成多位元）、延遲線、`LFSR` 亂數產生器的骨幹。

## 9.2 邊緣偵測器

### 規格

偵測輸入 `sig` 的變化：由 0 變 1 的瞬間輸出 `rise`；由 1 變 0 的瞬間輸出 `fall`。

### 想法

用一個正反器記住「**上一個時脈的** `sig`」叫 `sig_d`（d = delayed）。

- `rise`：現在是 1、上一個是 0 → `sig & ~sig_d`
- `fall`：現在是 0、上一個是 1 → `~sig & sig_d`

### 設計

```verilog
module edge_detect (
  input  wire clk,
  input  wire rst_n,
  input  wire sig,
  output wire rise,
  output wire fall
);
  reg sig_d;

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) sig_d <= 1'b0;
    else        sig_d <= sig;
  end

  assign rise =  sig & ~sig_d;
  assign fall = ~sig &  sig_d;
endmodule
```

### Testbench

這次在**上升緣當下**印出（看 DUT 在邊緣看到的值）：

```verilog
`timescale 1ns/1ps
module tb_edge;
  reg  clk = 1'b0;
  reg  rst_n, sig;
  wire rise, fall;

  edge_detect dut (.clk(clk), .rst_n(rst_n), .sig(sig), .rise(rise), .fall(fall));

  always #5 clk = ~clk;

  always @(posedge clk)
    if (rst_n)
      $display("t=%0d sig=%b rise=%b fall=%b", $time, sig, rise, fall);

  initial begin
    rst_n = 1'b0; sig = 1'b0;
    #22 rst_n = 1'b1;
    @(negedge clk) sig = 1'b1;        // t=30 往上
    repeat (3) @(negedge clk);        // t=40, 50, 60
    sig = 1'b0;                       // t=60 往下
    repeat (2) @(negedge clk);        // t=70, 80
    #1 $finish;
  end
endmodule
```

### 預期輸出

```
t=25 sig=0 rise=0 fall=0
t=35 sig=1 rise=1 fall=0
t=45 sig=1 rise=0 fall=0
t=55 sig=1 rise=0 fall=0
t=65 sig=0 rise=0 fall=1
t=75 sig=0 rise=0 fall=0
```

重點：`sig` 長長地維持在 1（t=35~55），但 **`rise` 只有在變化後的第一個時脈邊緣是 1**，其他時候是 0 → 它把「持續的位準」變成了「一個時脈寬的脈衝」。

💡 用途：偵測按鍵「被按下」的**瞬間**（只觸發一次），而不是「按住期間一直觸發」。

## 9.3 模 10 計數器（含進位）

### 規格

從 0 數到 9，然後回到 0（像時鐘的個位數）。當數到 9 且 `en=1`（下個時脈就要回 0）時，輸出 `carry` 脈衝，可用來驅動下一位（十位數）。

### 設計

```verilog
module counter_mod10 (
  input  wire       clk,
  input  wire       rst_n,
  input  wire       en,
  output reg  [3:0] cnt,
  output wire       carry
);
  assign carry = en && (cnt == 4'd9);

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
      cnt <= 4'd0;
    else if (en) begin
      if (cnt == 4'd9)
        cnt <= 4'd0;
      else
        cnt <= cnt + 4'd1;
    end
  end
endmodule
```

注意 `carry` 用 `&&`（條件判斷，第 5 章）。

### Testbench

```verilog
`timescale 1ns/1ps
module tb_mod10;
  reg        clk = 1'b0;
  reg        rst_n, en;
  wire [3:0] cnt;
  wire       carry;

  counter_mod10 dut (.clk(clk), .rst_n(rst_n), .en(en), .cnt(cnt), .carry(carry));

  always #5 clk = ~clk;

  always @(negedge clk)
    if (rst_n) $display("t=%0d cnt=%0d carry=%b", $time, cnt, carry);

  initial begin
    rst_n = 1'b0; en = 1'b0;
    #22 rst_n = 1'b1;
    @(negedge clk) en = 1'b1;          // t=30
    repeat (11) @(negedge clk);        // 到 t=140
    #1 $finish;
  end
endmodule
```

### 預期輸出

```
t=30 cnt=0 carry=0
t=40 cnt=1 carry=0
t=50 cnt=2 carry=0
t=60 cnt=3 carry=0
t=70 cnt=4 carry=0
t=80 cnt=5 carry=0
t=90 cnt=6 carry=0
t=100 cnt=7 carry=0
t=110 cnt=8 carry=0
t=120 cnt=9 carry=1
t=130 cnt=0 carry=0
t=140 cnt=1 carry=0
```

`carry` 只在 `cnt=9` 的那個時脈為 1，下一個時脈 `cnt` 回到 0。

## 9.4 使能脈衝與 LED 閃爍器（重要觀念）

### 問題：電路跑 50 MHz，但 LED 要每 0.5 秒才變一次，怎麼辦？

新手常見想法：「**自己做一個慢的時脈**」。例如：

```verilog
// ❌ 不建議：用計數器產生新時脈
reg slow_clk;
always @(posedge slow_clk) ...      // 另一個時脈域，問題一大堆
```

### ✅ 專業做法：**所有電路都用同一個主時脈，只是「偶爾」才動作**

做一個每 N 個時脈才出現一次的**使能脈衝 (tick)**，其他電路在 `tick=1` 時才更新：

```
clk   ─┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐┌┐
tick   ___________┐ ┌_________┐ ┌___      （每 N 個 clk 出現一次，寬度 1 個 clk）
```

### 使能脈衝產生器

```verilog
module tick_gen #(parameter N = 4) (
  input  wire clk,
  input  wire rst_n,
  output wire tick
);
  reg [15:0] cnt;

  assign tick = (cnt == N - 1);

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
      cnt <= 16'd0;
    else if (tick)
      cnt <= 16'd0;
    else
      cnt <= cnt + 16'd1;
  end
endmodule
```

`cnt` 數 0, 1, ..., N-1，數到 N-1 時 `tick=1`，下一拍回 0 重來。所以每 **N 個時脈**出現一次 `tick`。

### LED 閃爍器

```verilog
module blinker #(parameter N = 4) (
  input  wire clk,
  input  wire rst_n,
  output reg  led
);
  wire tick;

  tick_gen #(.N(N)) u_tick (.clk(clk), .rst_n(rst_n), .tick(tick));

  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
      led <= 1'b0;
    else if (tick)
      led <= ~led;           // 每個 tick 翻轉一次
  end
endmodule
```

這裡第一次出現「**模組裡面放另一個模組**」（`u_tick`），第 12 章會詳細說明。

### Testbench（用 N=4 方便觀察）

```verilog
`timescale 1ns/1ps
module tb_blink;
  reg  clk = 1'b0;
  reg  rst_n;
  wire led;

  blinker #(.N(4)) dut (.clk(clk), .rst_n(rst_n), .led(led));

  always #5 clk = ~clk;

  always @(negedge clk)
    $display("t=%0d led=%b", $time, led);

  initial begin
    rst_n = 1'b0;
    #22 rst_n = 1'b1;
    #145 $finish;
  end
endmodule
```

### 預期輸出

```
t=10 led=0
t=20 led=0
t=30 led=0
t=40 led=0
t=50 led=0
t=60 led=1
t=70 led=1
t=80 led=1
t=90 led=1
t=100 led=0
t=110 led=0
t=120 led=0
t=130 led=0
t=140 led=1
t=150 led=1
t=160 led=1
```

`led` 每 4 個時脈（40 ns）翻轉一次（在 t=55、95、135 翻轉）。

### 換成真實的開發板

假設開發板時脈 **50 MHz**，希望每 0.5 秒翻轉一次（閃爍頻率 1 Hz）：

```
N = 50,000,000 Hz × 0.5 s = 25,000,000
```

只要把參數改成 `blinker #(.N(25_000_000))`，並用 `[24:0]`（2²⁵ = 33,554,432 > 25,000,000）以上寬度的計數器。程式其餘部分不用改。

> 💡 **模擬時別直接用 25,000,000**，會跑非常久。模擬用小的 N（如 4），上板時才改大，這就是參數的好處。

## 9.5 設計時序電路的小流程

1. **畫時序圖**（手畫幾個時脈週期，標出每個週期各訊號的值）
2. 找出**需要記住什麼**（需要幾個正反器、幾位元）
3. 寫出**下一個值**是什麼（`if / else if`）
4. 別忘了**重置**
5. 在 testbench 裡預測結果，**跑出來和預測比對**

## 9.6 常見錯誤

| 錯誤 | 說明 | 解法 |
|------|------|------|
| `sig_d <= sig` 寫成 `sig_d = sig` | 時序用了 `=` | 用 `<=` |
| `tick` 太寬（多個時脈） | 計數器比較值差一 | 比較 `N-1`，並在 tick 時歸零 |
| 用計數器做新時脈 | 多時脈域、時序問題 | 改用使能脈衝 |
| 忘了重置 `led` | `led` 一直是 `x` | 重置時給初值 |
| 計數器寬度不夠 | 數不到 N | 位元數 ≥ `$clog2(N)` |
| 模擬時 N 設太大 | 跑很久不結束 | 模擬用小參數 |

## 本章小結

- **移位暫存器**：`q <= {q[N-2:0], din}`
- **邊緣偵測**：記住上一拍 `sig_d`，`rise = sig & ~sig_d`
- **模 N 計數器**：數到 N−1 時歸零
- **使能脈衝**取代自製時脈：所有電路共用一個 `clk`，用 `if (tick)` 控制更新
- 參數化 (`parameter`) 讓同一份程式能同時用於模擬與上板

## 小測驗

**Q1.** 4 位元移位暫存器目前是 `0101`，下一個時脈 `din = 1`，變成什麼？

<details><summary>看答案</summary>

`{q[2:0], din}` = `{101, 1}` = **`1011`**。
</details>

**Q2.** `rise = sig & ~sig_d` 中，`sig_d` 代表什麼？

<details><summary>看答案</summary>

`sig` 在**上一個時脈**的值（用正反器存起來的）。
</details>

**Q3.** 為什麼不建議用計數器產生新的「慢時脈」？

<details><summary>看答案</summary>

會形成多個時脈域，時序分析與跨時脈域傳資料都很麻煩。更好的做法是所有電路共用主時脈，用**使能脈衝**決定何時更新。
</details>

**Q4.** 50 MHz 時脈下，要讓 `tick` 每 1 ms 出現一次，`N` 應該是多少？

<details><summary>看答案</summary>

50,000,000 × 0.001 = **50,000**。
</details>
