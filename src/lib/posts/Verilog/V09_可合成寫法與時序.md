# 第 9 章　可合成寫法與時序概念

## 9.1 什麼是「可合成」？

**合成 (synthesis)** 是把 RTL 程式碼轉換成由邏輯閘與正反器組成的電路。Verilog 的語法很廣，但只有一部分能被合成。

### 可合成子集（常用）

| 類別 | 可用 |
|------|------|
| 資料型別 | `wire`、`reg`、`integer`（迴圈變數）、向量、陣列（記憶體） |
| 描述 | `assign`、`always @(*)`、`always @(posedge clk ...)` |
| 控制 | `if`、`case`/`casez`、有固定邊界的 `for`、`generate` |
| 運算 | 算術、位元、邏輯、移位、連接、條件運算子 |
| 其他 | `parameter`/`localparam`、`function`、模組階層 |

### 不可合成（僅供模擬）

| 項目 | 說明 |
|------|------|
| `#` 延遲 | 合成器忽略延遲 |
| `$display`、`$finish` 等系統工作 | 僅模擬 |
| `real`、`time` | |
| `===`、`!==` | 比較 X/Z 沒有硬體意義 |
| 階層參考（`tb.dut.x`） | |
| `initial`（用於 testbench） | FPGA 可用於暫存器初值，ASIC 不可 |
| `fork/join`、`wait`、`event` | |
| `force/release` | |
| 邊界不固定的迴圈 | |

> **經驗法則**：在 RTL 檔案中只用可合成子集；非可合成的東西全部放在 testbench。

## 9.2 常見的「意外硬體」

### Latch

見第 4 章。組合邏輯沒有涵蓋所有條件。

### 多重驅動

```verilog
// ❌ 兩個 always 驅動同一個 reg
always @(posedge clk) q <= a;
always @(posedge clk) q <= b;
```

### 敏感列表不完整

```verilog
// ❌ 漏掉 c，合成結果與模擬不同
always @(a or b) y = a & b & c;
// ✅
always @(*) y = a & b & c;
```

### 組合迴圈

見第 4 章。

### 未初始化導致的 X 傳播

模擬中 X 一旦進入控制路徑可能持續擴散。確認所有暫存器都有重置值。

## 9.3 可合成的 RAM 寫法

遵循固定的樣式，合成工具才能推導為 Block RAM：

```verilog
reg [7:0] mem [0:255];
always @(posedge clk) begin
  if (we) mem[waddr] <= din;
  dout <= mem[raddr];       // 同步讀
end
```

若寫成非同步讀（`assign dout = mem[raddr];`），通常只能用分散式 RAM（LUT RAM）或正反器實作，面積較大。

## 9.4 三態緩衝

```verilog
assign bus = oe ? data_out : 8'bz;
assign data_in = bus;
```

- 只建議在晶片 I/O 腳位使用
- 晶片內部的匯流排請改用多工器

## 9.5 時序概念

### Setup 與 Hold

```
         ┌──┐          ┌──┐
 clk  ───┘  └──────────┘  └───
            ↑ 取樣
 data ────────XXXXXXX─────────
              ←tsu→←th→
```

- **Setup time (tsu)**：時脈邊緣**之前**，資料必須穩定的時間
- **Hold time (th)**：時脈邊緣**之後**，資料必須維持的時間
- 違反 → 正反器可能進入**亞穩態 (metastability)**，輸出不確定

### 最高時脈頻率

```
T_clk ≥ T_clk→Q + T_logic(最長路徑) + T_setup + T_skew
```

**關鍵路徑 (critical path)**：延遲最長的組合邏輯路徑，決定 Fmax。

### 改善時序的方法

| 方法 | 說明 |
|------|------|
| **管線化 (Pipeline)** | 把長組合路徑切成多級，中間插入暫存器 |
| 平行化 | 以面積換速度 |
| 重新寫法 | 避免長串的加法鏈、深層 if-else |
| 重定時 (retiming) | 交給工具調整暫存器位置 |

### 管線化範例

```verilog
// 未管線：一個週期內完成 a*b + c*d
always @(posedge clk) y <= a*b + c*d;

// 兩級管線：延遲增加一個週期，但時脈可以更快
reg [15:0] p1, p2;
always @(posedge clk) begin
  p1 <= a*b;
  p2 <= c*d;
  y  <= p1 + p2;
end
```

## 9.5.1 重置的同步釋放

非同步重置在**釋放**時可能違反 recovery/removal 時間，建議「非同步置位、同步釋放」：

```verilog
module reset_sync (
  input  wire clk,
  input  wire arst_n,       // 外部非同步重置
  output wire rst_n         // 同步釋放後的內部重置
);
  reg r1, r2;
  always @(posedge clk or negedge arst_n) begin
    if (!arst_n) begin r1 <= 1'b0; r2 <= 1'b0; end
    else         begin r1 <= 1'b1; r2 <= r1;   end
  end
  assign rst_n = r2;
endmodule
```

## 9.6 跨時脈域 (CDC)

不同時脈的訊號之間傳遞資料會有亞穩態風險。

| 情境 | 作法 |
|------|------|
| 單一位元、慢變訊號 | 兩級（或三級）正反器同步器 |
| 單一位元脈衝 | 脈衝展寬後同步，或使用握手 |
| 多位元資料 | 握手協定（req/ack）+ 資料保持穩定；或非同步 FIFO |
| 計數器/指標 | 轉成**格雷碼**後再同步 |

⚠️ **絕對不要**把多位元匯流排的每個位元各自接一個同步器，各位元到達時間不同，會得到錯誤的組合值。

## 9.7 低功耗與時脈

- **不要**在 RTL 中以 `assign gated = clk & en;` 自行閘控時脈（會有毛刺、時序難以收斂）
- 需要「不要更新」時，使用 **enable**：`if (en) q <= d;`
- 真的需要閘控，使用元件庫提供的時脈閘控單元 (ICG)，或交給工具自動插入

## 9.8 編碼風格準則

1. 一個檔案一個模組，檔名＝模組名
2. 訊號命名：`rst_n`（低態有效）、`_q`（暫存器輸出）、`_d`/`_next`（下一值）
3. 所有 `if` 都有完整分支或預設值；所有 `case` 都有 `default`
4. 時序 `<=`、組合 `=`
5. 位元寬度全部明確，不依賴隱含擴展
6. 使用具名連接
7. 常數用 `parameter`/`localparam`，避免魔術數字
8. 一個訊號只被一個地方驅動
9. 狀態機採用三段式
10. 在 RTL 中避免使用 `#` 延遲

## 9.9 檢查清單：送去合成前

- [ ] Verilator lint 沒有警告（第 10 章）
- [ ] Yosys 合成沒有 latch、沒有未預期的 `$dlatch`
- [ ] 所有輸出都有驅動
- [ ] 所有暫存器有重置（或明確說明不需要）
- [ ] 跨時脈域訊號都已同步
- [ ] 測試涵蓋重置期間與重置釋放的情況
