# 第 1 章　簡介與開發環境

## 1.1 Verilog 是什麼？

Verilog 是一種**硬體描述語言 (HDL)**，用文字描述數位電路的結構與行為，可用於：

- **模擬 (simulation)**：在電腦上驗證電路行為
- **合成 (synthesis)**：轉換成真實的閘級電路，下載到 FPGA 或製成 ASIC

> ⚠️ Verilog 不是軟體程式語言。你是在「描述硬體」，每個 `always` 區塊、每個 `assign` 都代表**同時存在、並行運作**的電路。

### 簡史

| 年份 | 里程碑 |
|------|--------|
| 1984 | Gateway Design Automation 發明 Verilog |
| 1995 | IEEE 1364-1995（Verilog-95） |
| 2001 | IEEE 1364-2001（Verilog-2001）：ANSI 埠宣告、`generate`、`always @*` 等 |
| 2005 | IEEE 1364-2005：小修訂（`$clog2` 等） |
| 2009 起 | 併入 IEEE 1800（SystemVerilog），Verilog 成為其子集 |

本講義以 **Verilog-2001/2005** 為準，這也是目前各種開源工具最穩定支援的範圍。

## 1.2 數位設計流程

```
規格 → RTL 設計 (Verilog) → 功能模擬 → 合成 → 佈局佈線 → 時序驗證 → 下載/下線
```

- **RTL (Register Transfer Level)**：以暫存器與其間的資料傳輸描述電路，是最常用的設計層級
- 本講義主要處理前三步，並簡介合成（第 9–10 章）

## 1.3 描述層級

| 層級 | 說明 | 範例 |
|------|------|------|
| 行為級 (Behavioral) | 演算法式描述，常用於 testbench | `always`、`if`、`for` |
| RTL | 暫存器傳輸，可合成 | `always @(posedge clk)` |
| 閘級 (Gate) | 以基本邏輯閘連接 | `and g1(y, a, b);` |
| 開關級 (Switch) | 電晶體層級 | 很少使用 |

## 1.4 開源工具鏈

| 工具 | 用途 |
|------|------|
| **Icarus Verilog** (`iverilog`, `vvp`) | 編譯與模擬 |
| **GTKWave** | 觀看波形 (VCD/FST) |
| **Verilator** | 超高速模擬、**語法檢查 (lint)** |
| **Yosys** | 合成、電路統計與分析 |

## 1.5 第一個程式

檔名：`hello.v`

```verilog
module hello;
  initial begin
    $display("Hello, Verilog!");
    $finish;
  end
endmodule
```

```bash
iverilog -g2005 -o hello.vvp hello.v
vvp hello.vvp
```

## 1.6 第一個電路：AND 閘 + Testbench

`and_gate.v`

```verilog
module and_gate (
  input  wire a,
  input  wire b,
  output wire y
);
  assign y = a & b;
endmodule
```

`tb_and_gate.v`

```verilog
`timescale 1ns/1ps
module tb_and_gate;
  reg  a, b;
  wire y;

  and_gate dut (.a(a), .b(b), .y(y));

  initial begin
    $dumpfile("wave.vcd");
    $dumpvars(0, tb_and_gate);

    a = 0; b = 0; #10;
    a = 0; b = 1; #10;
    a = 1; b = 0; #10;
    a = 1; b = 1; #10;
    $finish;
  end

  initial $monitor("t=%0t a=%b b=%b y=%b", $time, a, b, y);
endmodule
```

```bash
iverilog -g2005 -Wall -o sim.vvp and_gate.v tb_and_gate.v
vvp sim.vvp
gtkwave wave.vcd
```

## 1.7 基本語法規則

- 區分大小寫
- 敘述以分號 `;` 結尾（`endmodule`、`end` 等關鍵字後不加）
- 註解：`// 單行`、`/* 多行 */`
- 識別字：字母或底線開頭，可含數字與 `$`
- 多行敘述以 `begin ... end` 包起來
- 數值格式：`<位元寬>'<進位><數值>`，例 `8'hFF`、`4'b1010`、`16'd100`；可用底線分隔：`16'hDEAD_BEEF`

## 1.8 四值邏輯

| 值 | 意義 |
|----|------|
| 0 | 邏輯低 |
| 1 | 邏輯高 |
| X | 未知（未初始化、衝突） |
| Z | 高阻抗（未驅動、三態） |

波形中看到紅色的 X，通常代表未初始化或有多重驅動，是除錯的重要線索。

## 1.9 `timescale`

```verilog
`timescale 1ns/1ps    // 時間單位 1ns，模擬精度 1ps
```

- `#10` 表示延遲 10 個**時間單位**（此例為 10 ns）
- 建議每個檔案開頭都寫，避免不同檔案單位不一致

## 練習

1. 在你的環境成功編譯並執行 `hello.v`。
2. 完成 AND 閘模擬，並在 GTKWave 中截圖或記錄波形。
3. 仿照 AND 閘，寫出 XOR 閘，並讓 testbench 自動印出真值表。
4. 故意把 `y` 的連接拿掉（不接 `.y(y)`），觀察波形與警告訊息。
