# 第 3 章　模組、埠與參數化

## 3.1 模組宣告

### ANSI 風格（Verilog-2001，推薦）

```verilog
module adder #(
  parameter WIDTH = 8
)(
  input  wire [WIDTH-1:0] a,
  input  wire [WIDTH-1:0] b,
  input  wire             cin,
  output wire [WIDTH-1:0] sum,
  output wire             cout
);
  assign {cout, sum} = a + b + cin;
endmodule
```

### 舊式（Verilog-95，閱讀舊程式碼時會遇到）

```verilog
module adder (a, b, cin, sum, cout);
  parameter WIDTH = 8;
  input  [WIDTH-1:0] a, b;
  input              cin;
  output [WIDTH-1:0] sum;
  output             cout;
  assign {cout, sum} = a + b + cin;
endmodule
```

## 3.2 埠的方向與型別

| 方向 | 內部型別 | 說明 |
|------|----------|------|
| `input` | wire | 只能讀 |
| `output` | wire 或 reg | 由 `assign` 驅動用 wire；由 `always` 驅動用 `output reg` |
| `inout` | wire | 雙向（三態），主要用於晶片腳位 |

```verilog
module counter (
  input  wire       clk,
  input  wire       rst_n,
  output reg  [3:0] cnt      // 在 always 中賦值，所以是 reg
);
```

## 3.3 實例化 (Instantiation)

```verilog
module top;
  reg  [7:0] x, y;
  wire [7:0] s;
  wire       c;

  // ✅ 具名連接（推薦）
  adder #(.WIDTH(8)) u_add (
    .a   (x),
    .b   (y),
    .cin (1'b0),
    .sum (s),
    .cout(c)
  );
endmodule
```

| 連接方式 | 語法 | 建議 |
|----------|------|------|
| 位置連接 | `adder u(x, y, 1'b0, s, c)` | 順序容易接錯，不建議 |
| 具名連接 | `.a(x)` | **推薦** |
| 未連接輸出 | `.cout()` | 允許，但建議註明原因 |
| 未連接輸入 | `.cin()` | ⚠️ 會變 Z，通常是錯誤 |

⚠️ 實例名稱慣例：`u_` 或 `i_` 開頭（如 `u_add`），便於在波形中辨認階層。

## 3.4 參數

```verilog
module fifo #(
  parameter DEPTH = 16,
  parameter WIDTH = 8
)(/* ... */);
  localparam ADDR_W = $clog2(DEPTH);   // $clog2：Verilog-2005
endmodule

// 覆寫參數
fifo #(.DEPTH(32), .WIDTH(16)) u_fifo (/* ... */);
fifo #(32, 16) u_fifo2 (/* ... */);     // 位置式（不推薦）
```

- `parameter`：可由實例化覆寫
- `localparam`：不可覆寫，用於由 parameter 計算出的衍生常數
- `defparam`：可在模組外覆寫，但**不建議使用**（可讀性差、合成工具支援度不一）

## 3.5 generate

### for-generate：重複實例化

```verilog
module full_adder (
  input  wire a, b, cin,
  output wire sum, cout
);
  assign sum  = a ^ b ^ cin;
  assign cout = (a & b) | (a & cin) | (b & cin);
endmodule

module rca #(parameter N = 8)(
  input  wire [N-1:0] a, b,
  input  wire         cin,
  output wire [N-1:0] sum,
  output wire         cout
);
  wire [N:0] c;
  assign c[0] = cin;

  genvar i;
  generate
    for (i = 0; i < N; i = i + 1) begin : g_fa
      full_adder u_fa (
        .a(a[i]), .b(b[i]), .cin(c[i]),
        .sum(sum[i]), .cout(c[i+1])
      );
    end
  endgenerate

  assign cout = c[N];
endmodule
```

- 迴圈變數必須宣告為 `genvar`
- 區塊必須命名（`begin : g_fa`），方便階層參考與除錯

### if-generate / case-generate

```verilog
generate
  if (WIDTH > 16) begin : g_wide
    // 寬版本
  end else begin : g_narrow
    // 窄版本
  end
endgenerate
```

## 3.7 編譯器指令

```verilog
`timescale 1ns/1ps
`define DATA_W 16
`include "defs.vh"

`ifdef DEBUG
  // 除錯用程式碼
`else
  // 一般程式碼
`endif
```

使用巨集時要加反引號：`` wire [`DATA_W-1:0] x; ``

⚠️ 巨集是**純文字取代**，沒有範圍與型別檢查，建議優先用 `parameter`/`localparam`；`` `define `` 較適合條件編譯與全域常數。

## 3.7.1 `function` 與 `task`（簡介）

```verilog
function [7:0] parity_ext;
  input [6:0] d;
  begin
    parity_ext = {^d, d};
  end
endfunction
```

- `function`：不可含時間控制（`#`、`@`、`wait`），至少一個輸入，回傳單一值
- `task`：可含時間控制，無回傳值（以 output 參數回傳）
- 詳見第 7 章

## 3.8 專案檔案組織建議

```
project/
├── rtl/        # 設計檔 (.v)
├── tb/         # testbench

```

一個檔案放一個模組，檔名與模組名相同。

## 練習
