# 第 2 章　資料型別與運算子

## 2.1 Net 與 Variable

Verilog 有兩大類資料物件：

| 類別 | 代表 | 用途 | 驅動方式 |
|------|------|------|----------|
| **Net（線）** | `wire` | 表示連線 | `assign`、模組輸出 |
| **Variable（變數）** | `reg`、`integer` | 在 `always`/`initial` 內賦值 | 程序性賦值 |

```verilog
wire        w;
reg         r;
wire [7:0]  bus;
reg  [15:0] data;
```

> ⚠️ `reg` **不一定**代表暫存器 (register)！它只是「可在 always 中被賦值的變數」。組合邏輯用 `reg` 也很常見，是否為正反器取決於 always 的敏感列表。

### 規則速記

- `assign` 的左邊必須是 **wire**
- `always` / `initial` 內賦值的左邊必須是 **reg**（或 integer 等變數）
- 模組的 **input** 在內部一定是 wire
- 模組的 **output** 可以是 wire 或 reg

## 2.2 其他資料型別

| 型別 | 說明 |
|------|------|
| `integer` | 32 位元有號整數，常用於迴圈變數與 testbench |
| `real` | 浮點數，僅供模擬，**不可合成** |
| `time` | 64 位元，儲存模擬時間 |
| `parameter` | 常數，可由外部覆寫 |
| `localparam` | 常數，僅模組內使用 |

```verilog
integer i;
real    r;
time    t;
parameter  WIDTH = 8;
localparam DEPTH = 16;
```

## 2.3 向量 (Vector)

```verilog
reg [7:0] a;     // 8 位元，a[7] 為最高位 (MSB)
reg [0:7] b;     // b[0] 為最高位（不常用，易混淆）
```

### 選取

```verilog
a[3]        // 單一位元
a[7:4]      // 部分選取（範圍必須是常數）
a[2 +: 4]   // 索引式部分選取：從第 2 位往上取 4 位，即 a[5:2]
a[5 -: 4]   // 從第 5 位往下取 4 位，即 a[5:2]
```

## 2.4 數字表示法

```verilog
8'b1010_1100    // 二進位
8'hAC           // 十六進位
8'd172          // 十進位
8'o254          // 八進位
4'bx01z         // 含 X 與 Z
'hFF            // 未指定寬度，預設至少 32 位元
-8'sd5          // 有號數：-5
```

⚠️ **未指定寬度的數字預設是 32 位元**，在位元寬度運算中容易出現意外（見 2.8）。

## 2.4.1 字串

```verilog
reg [8*12-1:0] msg;    // 可存 12 個字元
initial msg = "Hello";
initial $display("%s", msg);
```

## 2.5 陣列與記憶體

```verilog
reg [7:0] mem [0:15];        // 16 個 8 位元字組（記憶體）
reg [7:0] regs [0:3][0:3];   // 二維陣列（Verilog-2001）

initial begin
  mem[0] = 8'hAA;
  mem[1] = mem[0] + 1;
end
```

⚠️ 陣列元素**不能**整個一次賦值，也不能對陣列元素做位元範圍選取後直接當運算子輸入（需先讀到一個 `reg`）。

```verilog
reg [7:0] tmp;
always @(*) tmp = mem[addr];
// 取某一位元：tmp[3]
```

## 2.6 有號數

```verilog
reg signed [7:0] s;       // -128 ~ 127
wire signed [7:0] x;

s = -8'sd5;
s = $signed(8'hFF);       // -1
```

規則：運算式中只要**有一個運算元是無號數**，整個運算式就視為無號數。混用有號與無號是常見錯誤來源。

## 2.7 運算子

### 算術

`+  -  *  /  %  **`

### 關係

`<  <=  >  >=`

### 相等

| 運算子 | 說明 |
|--------|------|
| `==` `!=` | 邏輯相等，遇到 X/Z 結果為 X |
| `===` `!==` | 全等，X/Z 也逐位比較（僅模擬用，**不可合成**） |

### 邏輯

`&&`（且）、`||`（或）、`!`（非），結果為 1 位元。

### 位元運算

`&`、`|`、`^`、`~`、`~^`（XNOR），逐位元運算。

### 縮減運算（Reduction）

對向量所有位元做運算，得到 1 位元：

```verilog
&a    // 全部為 1 才為 1（AND）
|a    // 任一為 1 即為 1（OR）
^a    // 1 的個數為奇數時為 1（奇同位）
~^a   // 偶同位
```

### 移位

| 運算子 | 說明 |
|--------|------|
| `<<` `>>` | 邏輯移位，補 0 |
| `<<<` `>>>` | 算術移位；`>>>` 對**有號數**會做符號擴展 |

### 連接與複製

```verilog
{a, b}          // 連接
{4{1'b1}}       // 複製：4'b1111
{a[3:0], 2'b00} // 組合
{{4{s[3]}}, s}  // 符號擴展：把 4 位元有號數擴成 8 位元
```

### 條件運算子

```verilog
assign y = sel ? a : b;
```

### 運算子優先順序（由高到低，簡化）

```
單元運算子 (! ~ & | ^)  >  ** > * / % > + - > << >> > 關係 > 相等 > & > ^ > | > && > || > ?:
```

不確定時**加括號**。

## 2.8 位元寬度陷阱

```verilog
reg [7:0] a, b;
reg [8:0] sum;

sum = a + b;                // ✅ 運算式寬度取決於左右兩邊最大者（9 位元），進位被保留
wire [7:0] s8 = a + b;      // 進位被丟棄

// ❌ 位元寬度不一致
wire [7:0] x = 4'hF;        // 高位補 0，結果 8'h0F
```

進位保留的常見寫法：

```verilog
assign {cout, sum} = a + b + cin;
```

## 2.9 系統工作 (System Tasks)

| 工作 | 功能 |
|------|------|
| `$display` | 印出並換行 |
| `$write` | 印出不換行 |
| `$monitor` | 訊號變化時自動印出（同時只有一個有效） |
| `$strobe` | 在當前時間步結束時印出 |
| `$time` / `$realtime` | 目前模擬時間 |
| `$finish` / `$stop` | 結束 / 暫停模擬 |
| `$random` | 隨機整數 |

格式字元：`%b` 二進位、`%h` 十六進位、`%d` 十進位、`%0d` 去除前導空白、`%s` 字串、`%t` 時間、`%m` 階層名稱。

## 練習

1. 宣告 8 位元 `reg a = 8'b1011_0010`，計算 `&a`、`|a`、`^a`，並用 `$display` 檢查。
2. 把 4 位元有號數 `4'sb1010` 符號擴展成 8 位元（兩種方法：連接運算與 `$signed`）。
3. 宣告 `reg [7:0] mem [0:7]`，用 `for` 迴圈填入 0、2、4…，再用另一個迴圈印出。
4. 解釋為何 `8'hFF == 8'bxxxxxxxx` 的結果是 `x`，而 `===` 則是 0。
