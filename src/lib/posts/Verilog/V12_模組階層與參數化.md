# 第 12 章　模組階層與參數化

## 學習目標

- 會把小模組組合成大系統（結構化設計）
- 會用 `parameter` 讓模組可調整
- 會用 `generate for` 重複產生電路
- 認識階層參考（只用於 testbench）
- 學會安排專案資料夾

---

## 12.1 為什麼要分模組？

大電路不會寫成一大堆程式碼，而是像**樂高**：

- 把功能拆成小模組，每個模組只做一件事、各自測試
- 再用上層模組把它們**接起來**

```
           ┌───────────────────── top ─────────────────────┐
           │                                               │
  clk ────►│  ┌────────────┐  cnt   ┌──────────┐            │
  rst_n ──►│  │ counter    │───────►│ bcd7seg  │──► seg     │
  en ─────►│  │ _mod10     │        └──────────┘            │
           │  └────────────┘                                │
           └────────────────────────────────────────────────┘
```

好處：**容易測試、容易重用、容易除錯**。

## 12.2 複習：實例化

```verilog
模組名  實例名 ( .埠名(訊號), .埠名(訊號), ... );
```

規則：

- **具名連接**（`.埠名(訊號)`）永遠比位置連接好，不容易接錯
- 實例名稱慣例用 `u_` 開頭（如 `u_cnt`），波形裡一眼認出階層
- 輸出沒用到可以留空：`.carry()`

## 12.3 範例：計數器 + 七段顯示

使用第 7 章的 `bcd7seg` 與第 9 章的 `counter_mod10`（請放在同一資料夾）。

### 上層模組

```verilog
module counter_seg (
  input  wire       clk,
  input  wire       rst_n,
  input  wire       en,
  output wire [6:0] seg
);
  wire [3:0] cnt;                     // 兩個子模組之間的連線

  counter_mod10 u_cnt (
    .clk  (clk),
    .rst_n(rst_n),
    .en   (en),
    .cnt  (cnt),
    .carry()                          // 這裡用不到
  );

  bcd7seg u_seg (
    .bcd(cnt),
    .seg(seg)
  );
endmodule
```

重點：

- 內部連線用 `wire` 宣告（`cnt`）
- `counter_mod10` 的輸出 `cnt` 接到 `bcd7seg` 的輸入 `bcd`

### Testbench

```verilog
`timescale 1ns/1ps
module tb_counter_seg;
  reg        clk = 1'b0;
  reg        rst_n, en;
  wire [6:0] seg;

  counter_seg dut (.clk(clk), .rst_n(rst_n), .en(en), .seg(seg));

  always #5 clk = ~clk;

  always @(negedge clk)
    if (rst_n) $display("t=%0d cnt=%0d seg=%b", $time, dut.u_cnt.cnt, seg);

  initial begin
    rst_n = 1'b0; en = 1'b0;
    #22 rst_n = 1'b1;
    @(negedge clk) en = 1'b1;           // t=30
    repeat (4) @(negedge clk);          // 到 t=70
    #1 $finish;
  end
endmodule
```

`dut.u_cnt.cnt` 是**階層參考**：「`dut` 裡面的 `u_cnt` 裡面的 `cnt`」。

### 編譯

```bash
iverilog -g2005 -Wall -o sim.vvp bcd7seg.v counter_mod10.v counter_seg.v tb_counter_seg.v
vvp sim.vvp
```

⚠️ 要把**所有**用到的檔案都列出來。

### 預期輸出

```
t=30 cnt=0 seg=0111111
t=40 cnt=1 seg=0000110
t=50 cnt=2 seg=1011011
t=60 cnt=3 seg=1001111
t=70 cnt=4 seg=1100110
```

對照第 7 章七段顯示表：0 → `0111111`、1 → `0000110`、2 → `1011011`、3 → `1001111`、4 → `1100110` ✓。

### 階層參考的規則

- 只能用在 **testbench**（模擬用）
- **不可合成**，不能寫在要做成電路的設計裡
- 用來「偷看」內部訊號，方便除錯

## 12.4 參數 parameter

讓同一個模組有不同「版本」（例如不同位元寬度）。

### 定義

```verilog
module counter_n #(
  parameter W = 4
)(
  input  wire         clk,
  input  wire         rst_n,
  input  wire         en,
  output reg  [W-1:0] cnt
);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)    cnt <= {W{1'b0}};
    else if (en)   cnt <= cnt + 1'b1;
  end
endmodule
```

- `#( parameter W = 4 )`：宣告參數 `W`，**預設值 4**
- 後面用 `W` 取代寫死的數字：`[W-1:0]`、`{W{1'b0}}`

### 使用：覆寫參數

```verilog
counter_n #(.W(8)) u_cnt8 (.clk(clk), .rst_n(rst_n), .en(en), .cnt(cnt8));   // 8 位元
counter_n #(.W(3)) u_cnt3 (.clk(clk), .rst_n(rst_n), .en(en), .cnt(cnt3));   // 3 位元
counter_n          u_cntd (.clk(clk), .rst_n(rst_n), .en(en), .cnt(cntd));   // 用預設 4 位元
```

語法：`模組名 #(.參數名(值)) 實例名 (...)`。

同一份程式碼，用三種寬度，不用複製貼上。

### parameter 與 localparam

| | `parameter` | `localparam` |
|---|-------------|--------------|
| 能從外面覆寫嗎 | ✅ | ❌ |
| 用途 | 給使用者調整的設定 | 內部固定常數、由參數算出來的值 |

```verilog
module fifo #(parameter DEPTH = 16) (...);
  localparam ADDR_W = $clog2(DEPTH);   // 由 DEPTH 算出，使用者不用管
```

`$clog2(N)`：「≥ log₂N 的最小整數」，例如 `$clog2(16)` = 4、`$clog2(17)` = 5，常用來算位址位元數。

### 常見用途

- 資料寬度（`W`）
- FIFO 深度
- **計時常數**（模擬用小值，上板用大值，第 9 章）

## 12.5 generate for：重複產生電路

要接 8 個一模一樣的電路，不想複製貼上 8 次：

```verilog
genvar i;
generate
  for (i = 0; i < 8; i = i + 1) begin : g_name
    // 這裡的內容會被產生 8 份
  end
endgenerate
```

規則：

- 迴圈變數必須宣告成 **`genvar`**（不是 `integer`）
- `begin` 後面要**取名字**（`: g_name`）
- 這是在「**畫電路時**」重複，不是「執行時」重複

### 範例：N 位元漣波進位加法器

由 N 個全加器串起來，前一個的進位 `cout` 接到下一個的 `cin`：

```
 a[0] b[0]      a[1] b[1]      a[2] b[2]
   │   │          │   │          │   │
 ┌─▼───▼─┐  c[1]┌─▼───▼─┐ c[2] ┌─▼───▼─┐  c[3]
 │  FA   ├─────►│  FA   ├─────►│  FA   ├─────► ...
 └───┬───┘      └───┬───┘      └───┬───┘
cin─►c[0]           │              │
     sum[0]       sum[1]         sum[2]
```

```verilog
module full_adder (
  input  wire a, b, cin,
  output wire sum, cout
);
  assign sum  = a ^ b ^ cin;
  assign cout = (a & b) | (a & cin) | (b & cin);
endmodule

module rca #(parameter N = 4) (
  input  wire [N-1:0] a, b,
  input  wire         cin,
  output wire [N-1:0] sum,
  output wire         cout
);
  wire [N:0] c;                    // c[0]=cin, c[N]=cout，共 N+1 條進位線
  assign c[0] = cin;

  genvar i;
  generate
    for (i = 0; i < N; i = i + 1) begin : g_fa
      full_adder u_fa (
        .a   (a[i]),
        .b   (b[i]),
        .cin (c[i]),
        .sum (sum[i]),
        .cout(c[i+1])
      );
    end
  endgenerate

  assign cout = c[N];
endmodule
```

### 逐行解說

- `wire [N:0] c;`：N+1 條進位線，因為 N 個全加器共有 N+1 個進位點
- `c[0] = cin`：最低位的進位輸入
- 迴圈第 `i` 圈：第 `i` 個全加器吃 `a[i]`、`b[i]`、`c[i]`，產生 `sum[i]` 與 `c[i+1]`
- `c[i+1]` 就是下一圈的 `c[i]` → 進位串起來了
- `cout = c[N]`

### 自我檢查 testbench（窮舉）

```verilog
`timescale 1ns/1ps
module tb_rca;
  parameter N = 4;

  reg  [N-1:0] a, b;
  reg          cin;
  wire [N-1:0] sum;
  wire         cout;
  integer i, j, k, errors, count;

  rca #(.N(N)) dut (.a(a), .b(b), .cin(cin), .sum(sum), .cout(cout));

  initial begin
    errors = 0;
    count  = 0;
    for (i = 0; i < (1 << N); i = i + 1)
      for (j = 0; j < (1 << N); j = j + 1)
        for (k = 0; k < 2; k = k + 1) begin
          a = i[N-1:0];
          b = j[N-1:0];
          cin = k[0];
          #1;
          count = count + 1;
          if ({cout, sum} !== i + j + k) begin
            errors = errors + 1;
            $display("ERROR: %0d + %0d + %0d got %0d", i, j, k, {cout, sum});
          end
        end

    if (errors == 0) $display("PASSED: %0d cases", count);
    else             $display("FAILED: %0d errors", errors);
    $finish;
  end
endmodule
```

```bash
iverilog -g2005 -Wall -o sim.vvp rca.v tb_rca.v
vvp sim.vvp
```

預期輸出（N=4 時 16 × 16 × 2 = 512 種組合）：

```
PASSED: 512 cases
```

想試 8 位元，不用改程式，從命令列覆寫最上層參數（Icarus 的 `-P` 選項，寫法依版本可能略有差異，若不行就直接把 `parameter N = 4` 改成 8）：

```bash
iverilog -g2005 -Ptb_rca.N=8 -o sim.vvp rca.v tb_rca.v
vvp sim.vvp
```

預期：`PASSED: 131072 cases`（256 × 256 × 2）。

## 12.7 專案資料夾安排

```
my_project/
├── rtl/             # 設計檔（要做成電路的）
│   ├── full_adder.v
│   ├── rca.v
│   └── counter_n.v
├── tb/              # testbench（只用在模擬）
│   └── tb_rca.v
├── sim/             # 模擬輸出（vvp 檔、vcd 波形）
├── Makefile
└── README.md
```

規則：

- **一個檔案一個模組**，檔名 = 模組名（`rca.v` 裡面是 `module rca`）
- `rtl/` 只放可合成的設計；`tb/` 只放測試
- 編譯時用萬用字元：`iverilog -g2005 -o sim/sim.vvp rtl/*.v tb/tb_rca.v`

## 12.8 常見錯誤

| 錯誤 | 症狀 | 解法 |
|------|------|------|
| `Unknown module type: xxx` | 編譯時漏了某個檔案 | 把所有 `.v` 列進編譯指令 |
| 埠接錯順序（位置連接） | 結果怪怪的 | 改用具名連接 |
| 輸出接到 `reg` | 編譯錯誤 | 子模組的輸出接到 `wire` |
| 兩個輸出接到同一條線 | 出現 `x` | 一條線只能有一個驅動者 |
| `generate for` 用 `integer` | 編譯錯誤 | 改用 `genvar` |
| generate 區塊沒取名 | 警告或階層不清楚 | 加 `: g_name` |
| 位元寬度不一致 | 警告 `port width mismatch` | 檢查兩端位元數 |
| 參數寫在錯誤的地方 | 沒有覆寫成功 | `模組名 #(.W(8)) 實例名 (...)` |
| 實例化埠漏接 | 該輸入是 `z` | 每個輸入都要接 |

## 本章小結

- 把大設計拆成**小模組**，用上層模組連接
- 實例化：`模組名 #(.參數(值)) 實例名 (.埠(訊號));`
- `parameter` 可覆寫；`localparam` 是內部常數
- `generate for` + `genvar` 重複產生電路；區塊要命名
- 階層參考 `dut.u_cnt.cnt` 只用在 testbench
- 一個檔案一個模組

## 小測驗

**Q1.** `counter_n #(.W(6)) u (...)` 的 `cnt` 會是幾位元？最大值多少？

<details><summary>看答案</summary>

6 位元，最大值 2⁶ − 1 = **63**。
</details>

**Q2.** `$clog2(100)` 等於多少？

<details><summary>看答案</summary>

2⁶ = 64 &lt; 100 ≤ 128 = 2⁷，所以 **7**。
</details>

**Q3.** 為什麼 `generate for` 的變數不能用 `integer`？

<details><summary>看答案</summary>

因為 `generate` 是在「建立電路的階段」展開，不是在模擬執行時迴圈。需要一種只在建立電路時存在的變數，就是 `genvar`。
</details>

**Q4.** 階層參考可以寫在要合成的設計裡嗎？

<details><summary>看答案</summary>

**不行**。階層參考只能用在 testbench（模擬）。
</details>

## 練習

1. 把 `counter_mod10` 用在**兩位數計數器**（00~99）：個位數 `carry` 接到十位數的 `en`。用兩個 `bcd7seg` 顯示。寫 testbench 數到 `cnt_tens=1, cnt_ones=0`（即 10）時檢查。
2. 寫一個參數化的 **N 位元 2-to-1 多工器** `mux2 #(.W(8))`，分別實例化 8 位元與 16 位元版本。
3. 用 `generate for` 實作 **N 位元反相器陣列**（輸入 `a[N-1:0]`，輸出每一位反相），並用 testbench 驗證。
4. 做一個**可調長度的移位暫存器**：把第 9 章的 `shift_reg` 用 `parameter N` 實例化成 4、8 位元各一個。
5. 把 `rca` 做成**加減法器**：新增輸入 `sub`，`sub=1` 時計算 `a − b`。（提示：每個 `b[i]` 先與 `sub` 做 XOR，並把 `sub` 當作 `cin`。）
