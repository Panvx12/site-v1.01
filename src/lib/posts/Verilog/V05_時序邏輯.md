# 第 5 章　時序邏輯

## 5.1 基本正反器

```verilog
always @(posedge clk) begin
  q <= d;
end
```

- 敏感列表用邊緣：`posedge`（上升緣）、`negedge`（下降緣）
- 使用**非阻塞賦值 `<=`**
- 一個 always 區塊對應一組暫存器

## 5.2 阻塞與非阻塞的差異

```verilog
// 非阻塞：所有右邊先用「舊值」算好，時間步結束時一起更新
always @(posedge clk) begin
  a <= b;
  b <= a;        // 真正交換：a、b 互換
end

// 阻塞：依序執行，後面看到前面更新後的值
always @(posedge clk) begin
  a = b;
  b = a;         // b 得到的是新的 a，即 a、b 都變成舊 b
end
```

### 簡化的模擬事件順序

1. **Active 區**：執行 `=`、計算 `<=` 的右邊
2. **NBA（非阻塞賦值更新）區**：更新 `<=` 的左邊
3. 若更新後觸發新事件，回到 Active 區

這就是為什麼多個正反器能在同一個時脈邊緣「同時」更新、不受先後順序影響。

### 賦值使用準則

| 情況 | 使用 |
|------|------|
| 時序邏輯（`posedge`/`negedge`） | `<=` |
| 組合邏輯（`@(*)`） | `=` |
| Testbench 激勵 | 依情境，常用 `=` |

⚠️ 在時序 always 中用 `=` 會造成模擬競爭 (race condition)，結果可能與合成結果不同。

## 5.3 重置 (Reset)

### 同步重置

```verilog
always @(posedge clk) begin
  if (!rst_n) q <= 8'h00;
  else        q <= d;
end
```

### 非同步重置

```verilog
always @(posedge clk or negedge rst_n) begin
  if (!rst_n) q <= 8'h00;
  else        q <= d;
end
```

| 類型 | 優點 | 缺點 |
|------|------|------|
| 同步 | 時序分析單純、抗雜訊 | 需要時脈才能重置 |
| 非同步 | 不依賴時脈 | 釋放 (deassert) 時需與時脈同步，否則可能亞穩態 |

建議做法：**非同步重置、同步釋放**（第 9 章有範例）。

## 5.4 帶使能的暫存器

```verilog
always @(posedge clk or negedge rst_n) begin
  if (!rst_n)    q <= 8'h00;
  else if (en)   q <= d;      // 沒有 else：保持原值，這是正常的暫存器行為
end
```

⚠️ 時序邏輯中「沒寫 else」是正常的（正反器保持原值），這和組合邏輯的 latch 問題不同。

## 5.5 常見時序電路

### 計數器（本講義後續章節將重複使用）

```verilog
module counter #(parameter W = 4)(
  input  wire         clk,
  input  wire         rst_n,
  input  wire         en,
  output reg  [W-1:0] cnt
);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)    cnt <= {W{1'b0}};
    else if (en)   cnt <= cnt + 1'b1;
  end
endmodule
```

### 上下計數器（含載入）

```verilog
module updown #(parameter W = 8)(
  input  wire         clk, rst_n,
  input  wire         load, up,
  input  wire [W-1:0] din,
  output reg  [W-1:0] q
);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n)      q <= {W{1'b0}};
    else if (load)   q <= din;
    else if (up)     q <= q + 1'b1;
    else             q <= q - 1'b1;
  end
endmodule
```

### 移位暫存器

```verilog
module shift_reg #(parameter N = 8)(
  input  wire         clk, rst_n, din,
  output reg  [N-1:0] q
);
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) q <= {N{1'b0}};
    else        q <= {q[N-2:0], din};
  end
endmodule
```

### 邊緣偵測

```verilog
module edge_detect (
  input  wire clk, rst_n, sig,
  output wire rise, fall
);
  reg sig_d;
  always @(posedge clk or negedge rst_n) begin
    if (!rst_n) sig_d <= 1'b0;
    else        sig_d <= sig;
  end
  assign rise =  sig & ~sig_d;
  assign fall = ~sig &  sig_d;
endmodule
```

## 5.6 組合與時序分開寫

建議把「下一狀態/下一值」的組合邏輯與暫存器分開，便於閱讀與除錯：

```verilog
reg [3:0] cnt, cnt_next;

always @(*) begin                 // 組合：算下一值
  cnt_next = cnt;
  if (en) cnt_next = cnt + 1'b1;
end

always @(posedge clk or negedge rst_n) begin   // 時序：存起來
  if (!rst_n) cnt <= 4'd0;
  else        cnt <= cnt_next;
end
```

## 5.7 時脈與多時脈

- 一個 always 區塊只用一個時脈（及可選的非同步重置）
- 不要在 RTL 中自己用組合邏輯產生時脈（如 `assign clk2 = clk & en;`）；需要降低更新率時，用**使能 (enable)** 而不是新時脈
- 跨時脈域資料傳輸要用同步器（第 8、9 章）

## 5.8 常見陷阱

⚠️ 時序 always 中使用阻塞賦值 `=`
⚠️ 同一個 `reg` 在多個 always 中被賦值（多重驅動）
⚠️ 重置條件寫成 `if (rst)` 卻接了低態有效的重置訊號，極性不一致
⚠️ 敏感列表有 `negedge rst_n` 卻沒有在 if 中判斷它
