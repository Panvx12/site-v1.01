# 第 4 章　資料型別與向量

## 學習目標

- 分清楚 `wire` 和 `reg`
- 會宣告多位元的向量，並取出其中某些位元
- 會讀、會寫 Verilog 的數字格式（例如 `8'hFF`）
- 會用 `{ }` 把位元拼起來
- 認識 `x`（未知）與 `z`（高阻）

---

## 4.1 wire 與 reg：最容易搞混的兩個

### 先說結論

| | `wire` | `reg` |
|---|--------|-------|
| 白話 | **電線** | **可以被「寫入」的變數** |
| 怎麼給值 | `assign`，或接到模組的輸出 | 在 `always` / `initial` 裡用 `=` 或 `<=` |
| 會記住值嗎 | 不會，只是傳遞 | 在模擬裡會保持，直到被改寫 |

💡 比喻：`wire` 像**水管**，水從 A 流到 B，水管本身不存水；`reg` 像**便條紙**，你寫了什麼就留在上面，直到有人重寫。

### 最重要的規則（背起來）

1. **`assign` 的左邊 → 必須是 `wire`**
2. **`always` 或 `initial` 裡被賦值的 → 必須是 `reg`**
3. 模組的 **input** 在模組內是 `wire`
4. 模組的 **output**：用 `assign` 驅動就寫 `output wire`，在 `always` 裡驅動就寫 `output reg`

### ⚠️ 超級常見的誤會

> **`reg` 不一定會變成暫存器（正反器）！**

`reg` 只是 Verilog 語法上的名稱，代表「可以在 always 裡被賦值」。會不會變成正反器，要看 `always` 是怎麼寫的（第 6、8 章會說明）。所以**不要因為看到 `reg` 就以為是記憶元件**。

## 4.2 向量（多位元訊號）

```verilog
wire        a;          // 1 位元
wire [7:0]  data;       // 8 位元，編號 7 到 0
reg  [3:0]  count;      // 4 位元
```

`[7:0]` 的意思：**最高位元編號 7（MSB），最低位元編號 0（LSB）**。

```
data[7] data[6] data[5] data[4] data[3] data[2] data[1] data[0]
 (MSB)                                                  (LSB)
```

位元數 = 高位 − 低位 + 1。`[7:0]` → 8 位元；`[3:0]` → 4 位元；`[0:0]` 或不寫 → 1 位元。

✅ 習慣：**一律寫成 `[高:低]`，低位是 0**（如 `[7:0]`），不要寫 `[0:7]`。

### 取出其中某些位元

```verilog
reg [7:0] a;

a[7]        // 取第 7 位（最高位）
a[0]        // 取第 0 位（最低位）
a[3:0]      // 取低 4 位元
a[7:4]      // 取高 4 位元
```

⚠️ `[3:0]` 這種範圍的**數字必須是常數**（不能放變數）。

## 4.3 數字怎麼寫

格式：`位元寬度'進位數值`

```
 8'hA5
 │ │└── 數值（A5）
 │ └─── 進位：b=二進位, o=八進位, d=十進位, h=十六進位
 └───── 位元寬度：8 位元
```

| 寫法 | 位元數 | 意思 | 十進位 |
|------|:-----:|------|:-----:|
| `4'b1010` | 4 | 二進位 1010 | 10 |
| `8'hFF` | 8 | 十六進位 FF | 255 |
| `8'd100` | 8 | 十進位 100 | 100 |
| `1'b0` | 1 | 單一位元 0 | 0 |
| `16'hBEEF` | 16 | 十六進位 BEEF | 48879 |
| `8'b1010_1100` | 8 | `_` 只是分隔，方便閱讀 | 172 |

### ⚠️ 不寫位元數會怎樣？

```verilog
a = 5;        // 寫 5，沒有位元數
```

沒指定寬度的數字預設是 **32 位元**。有時沒影響，有時會造成意外，所以**養成習慣，寫上位元數**，例如 `4'd5`。

### 數字太大放不下？

```verilog
reg [3:0] x;
x = 8'hFF;    // 8 位元的 FF 放進 4 位元的 x，只留低 4 位 → x = 4'hF
```

放不下時，**高位會被截掉**，不會報錯（最多有警告），所以要自己小心。

## 4.4 🧪 動手做：位元選取實驗

檔名 `bits_demo.v`：

```verilog
module bits_demo;
  reg [7:0] a;

  initial begin
    a = 8'b1010_0101;

    $display("a        = %b", a);
    $display("hex      = %h", a);
    $display("dec      = %0d", a);
    $display("a[7]     = %b", a[7]);
    $display("a[0]     = %b", a[0]);
    $display("a[3:0]   = %b", a[3:0]);
    $display("a[7:4]   = %b", a[7:4]);
    $finish;
  end
endmodule
```

先自己用手算預測，再執行：

```bash
iverilog -g2005 -o bits.vvp bits_demo.v
vvp bits.vvp
```

### 預期輸出

```
a        = 10100101
hex      = a5
dec      = 165
a[7]     = 1
a[0]     = 1
a[3:0]   = 0101
a[7:4]   = 1010
```

驗算：`1010 0101` = 0xA5 = 10×16 + 5 = 165 ✓。

## 4.5 連接運算 `{ }` 與複製

### 連接：把位元拼起來

```verilog
{a, b}          // 把 a 放左邊（高位），b 放右邊（低位）
```

例：

```verilog
reg [3:0] hi, lo;
reg [7:0] byte_val;

hi = 4'b1010;
lo = 4'b0101;
byte_val = {hi, lo};      // 結果 8'b1010_0101
```

### 用途 1：交換高低 4 位元

```verilog
{a[3:0], a[7:4]}      // 若 a = 1010_0101，結果 0101_1010
```

### 用途 2：左移補 0

```verilog
{a[6:0], 1'b0}        // 整個往左移一位，最低位補 0
```

### 複製 `{N{...}}`

```verilog
{4{1'b1}}             // 1111
{3{2'b10}}            // 101010
{8{1'b0}}             // 00000000
```

最常用：**把 N 位元的值全部設成 0**：`{N{1'b0}}`。

### 實驗

```verilog
module concat_demo;
  reg [7:0] a;
  initial begin
    a = 8'b1010_0101;
    $display("swap    = %b", {a[3:0], a[7:4]});
    $display("shift   = %b", {a[6:0], 1'b0});
    $display("repeat  = %b", {4{1'b1}});
    $display("repeat2 = %b", {3{2'b10}});
    $finish;
  end
endmodule
```

預期輸出：

```
swap    = 01011010
shift   = 01001010
repeat  = 1111
repeat2 = 101010
```

驗算 `shift`：`a[6:0]` = `0100101`，後面補 `0` → `01001010` ✓。

## 4.6 四種邏輯值：0、1、x、z

| 值 | 名稱 | 意思 | 什麼時候看到 |
|:--:|------|------|-------------|
| `0` | 低 | 邏輯 0 | |
| `1` | 高 | 邏輯 1 | |
| `x` | 未知 | 不知道是 0 還是 1 | **還沒賦值的 reg**、有衝突時 |
| `z` | 高阻 | 沒有東西在驅動 | **沒接線的輸入**、三態匯流排 |

### 實驗

```verilog
module xz_demo;
  reg  [3:0] r;
  wire [3:0] w;           // 沒有任何東西驅動它

  initial begin
    $display("before assign: r=%b", r);
    $display("undriven wire: w=%b", w);
    r = 4'b1010;
    $display("after  assign: r=%b", r);
    $finish;
  end
endmodule
```

預期輸出：

```
before assign: r=xxxx
undriven wire: w=zzzz
after  assign: r=1010
```

💡 **除錯口訣**：

- 看到 **`x`** → 通常是「忘了給初始值」或「被兩個地方同時驅動」
- 看到 **`z`** → 通常是「線沒接」

## 4.7 其他常用型別

| 型別 | 說明 | 用在哪 |
|------|------|--------|
| `integer` | 32 位元整數（有號） | 迴圈變數、testbench |
| `parameter` | 常數，可從外面改 | 參數化（第 12 章） |
| `localparam` | 常數，不能從外面改 | 模組內部常數、狀態編碼 |
| 陣列 `reg [7:0] mem [0:15]` | 16 個 8 位元的格子 | 記憶體 |

### parameter / localparam 小預覽

```verilog
localparam WIDTH = 8;
reg [WIDTH-1:0] data;      // 等於 reg [7:0] data;
```

好處：以後只要改 `WIDTH` 一處，其他跟著變。

### 陣列（記憶體）預覽

```verilog
reg [7:0] mem [0:3];       // 4 個格子，每格 8 位元

initial begin
  mem[0] = 8'h11;
  mem[1] = 8'h22;
  $display("%h %h", mem[0], mem[1]);   // 11 22
end
```

⚠️ 注意位置：**向量寬度寫在名字前面 `[7:0]`，格子數寫在名字後面 `[0:3]`。**

## 4.8 常見錯誤

| 錯誤 | 說明 | 解法 |
|------|------|------|
| `assign` 的左邊用 `reg` | 編譯錯誤 | 改 `wire` |
| `always` 裡賦值給 `wire` | 編譯錯誤 | 改 `reg` |
| 寫 `[0:7]` 又用 `a[7:4]` | 位元順序顛倒 | 統一寫 `[7:0]` |
| 位元寬度不一致 | 高位被截掉 / 補 0 | 寫上位元數，注意寬度 |
| 把 `1'b1`、`1'h1` 當不同東西 | 其實一樣是 1 | 不要緊張 |
| 看到 `x` 不管它 | 後面全部會被汙染 | 找出沒初始化的訊號 |

## 本章小結

- `wire` 用 `assign`；`reg` 用 `always`/`initial`
- `reg` 不一定是暫存器
- `[7:0]` 表示 8 位元，高位寫前面
- 數字格式 `位元數'進位值`，例 `8'hFF`
- `{ }` 拼接、`{N{ }}` 複製
- `x` = 未知、`z` = 沒接

## 小測驗

**Q1.** `reg [3:0] a;` 一共幾位元？最大值是多少？

<details><summary>看答案</summary>

**4 位元**，無號最大值 **15**（`4'b1111`）。
</details>

**Q2.** `8'b1100_0011` 的十六進位是多少？

<details><summary>看答案</summary>

`1100` = C，`0011` = 3，所以是 **`8'hC3`**。
</details>

**Q3.** 若 `a = 8'hF0`，`a[7:4]` 和 `a[3:0]` 分別是什麼？

<details><summary>看答案</summary>

`F0` = `1111 0000`，所以 `a[7:4] = 4'b1111`（F），`a[3:0] = 4'b0000`（0）。
</details>

**Q4.** `{2'b10, 3'b110}` 的結果是幾位元？是什麼？

<details><summary>看答案</summary>

2 + 3 = **5 位元**，內容 `5'b10110`。
</details>

**Q5.** 模擬時某個 `reg` 的值一直是 `x`，最可能的原因是什麼？

<details><summary>看答案</summary>

**沒有給初始值**（也沒有重置），所以值是未知。
</details>

## 練習

1. 宣告 `reg [15:0] w = 16'hBEEF`（或在 `initial` 內賦值），用 `$display` 印出 `w[15:8]`（預期 `be`）與 `w[7:0]`（預期 `ef`）。
2. 用連接運算把 `8'hBE` 和 `8'hEF` 合成一個 16 位元的值，印出 `%h`（預期 `beef`）。
3. 寫出把 8 位元 `a` **整個左右反轉**（bit0 變 bit7…）的運算式，並驗證。（提示：`{a[0], a[1], a[2], a[3], a[4], a[5], a[6], a[7]}`）
4. 宣告 `reg [7:0] mem [0:7]`，用 `for` 迴圈填入 `i * 2`，再印出每一格。
